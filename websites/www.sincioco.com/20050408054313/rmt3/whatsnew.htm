What's Fixed in RMT 3.0 - Build 40 - A?

September 12, 2003, 9:00 p.m. Pacific Time
Module Description
Data Migration Tool The Data Migration Tool was crashing/broken in Build 40.  It is now fixed in Build 40 - A.
What's New in RMT 3.0 - Build 40?

September 11, 2003, 2:00 p.m. Pacific Time
Module Description
EQ Guild Dump Parser The Notes from EQ's Guild Dump will now be appended to the Player's Notes.
Class You can now add, edit, delete classes in RMT.
Level You can now add, edit, delete levels in RMT.
Tools Menu The Data Migration Tool, EQ Log Parser, Guild Dump Parser, Racalculate Raid Points have been moved to the new Tools Menu.
Ungroup All Attendees You can now ungroup all Attendees from the Tools menu.  Please note that the raid gets auto-saved after this operation is done.
Auto-Group There is now an option to automatically have RMT assign players to their previous group based on the following:
  1. Auto-group based on the last raid.
  2. Auto-group based on the last raid of the same zone.
Please note that the raid gets auto-saved after this operation is done.
Remove All Loot Awards You can now remove all Loots awarded to all the Attendees.  Please note that the raid gets auto-saved after this operation is done.
What's Fixed in RMT 3.0 - Build 40?
Module Description
Attributes Deleting a custom attribute from the Attribute window will now properly remove that attribute in the Attribute drop-down list in the Attendee window.
