What's New in RMT 3.0 - Build 32?

May 12, 2003, 10:00 a.m. Pacific Time
Module Description
Loot History You can now see all players who have been awarded a particular loot via the History menu (the Player menu has been renamed to History menu).
Recalculate Raid Points In the Help menu there is now an option to force RMT to recalculate all players' raid points across all raids.
Import EQ Players from EQ Log You can now import players by having RMT parse through your EQ Log in REAL TIME!

All players in the zone, LFG or not, will be picked up. Even players in channels! Linkdead folks are automatically ignored. Traders in Bazaars will automatically be ignored as well.

How to setup RMT to read your Log File in Real Time
  1. Log on to EQ and be sure that your log file contain today's logs. For instance, go to Nexus and type "/".
  2. Start RMT (Build 31 or higher), and create a new Raid.
  3. Go to the File Menu and select Import Players from EQ Log (or press Ctrl + G).
  4. Click the Browse button and browse to your character's EQ Log file.
  5. Sit back and relax as RMT parses through your log file in real time!
  6. Select the players you want to import.
  7. Click on the Import button to import the players to your raid.
  8. Optional Step. After you've browse through all the players, click the Mark All button. This turns all the players into color grey. This will make it easy for you to see new players that gets added in real time.
NOTE: Remember to type "/" in EQ periodically for RMT to pick up new players in the zone.
Timers (Untested) A early working state of the Timer feature is available for testing.
