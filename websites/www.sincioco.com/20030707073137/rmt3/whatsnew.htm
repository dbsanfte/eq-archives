What's New in RMT 3.0 - Build 39?

July 07, 2003, 12:00 a.m. Pacific Time
Module Description
XML Import/Export RMT will now export and import XML files which can be used to share raid information with other officers in the guild or other raid leaders.  It can also be used to "clone" or copy a raid to be used as a starting point for a new raid (please be sure to delete any loot awards if you plan to rename the raid to a different name).

When importing an XML file, player notes are automatically added to any existing player notes (if they differ). Also, the total raid points is ignored, as it is dynamically calculated by RMT.

Data Migration Tool Player notes will now be automatically added to any existing player notes (if they differ).
