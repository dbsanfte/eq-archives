Console Parser v0.33

 

The purpose of this Parser is to provide real-time updating of your EQ statistics as you play.  Currently the Parser is a Console-Mode only application, meaning it will run in a DOS box only.   I originally wrote this entirely for myself, but it has proven a useful tool for a lot of EQ players, so I’m posting it here.  It will provide you detailed info about:

 

  • Total Combat Damage
  • Total Slash / Crush / Backstab / Pierce / Punch / Kick / Bash / Non-Melee Damage
  • Percentage of Total Damage for All Supported Damage Types
  • Percentage of Total Hits for All Supported Damage Types
  • Critical Hit / Crippling Blow Percentage Calculation
  • Critical Hit / Crippling Blow Increase-to-DPS Calculation
  • On-the-Fly DPS Calculation
  • On-the-Fly DTPS Calculation (Damage Taken Per Second)
  • Average Critical Hit and Normal Hit Calculation
  • Total Enemy Misses / Hits
  • Total Player Dodges / Ripostes / Parries / Blocks / Rune Absorbs

 

To active Real-Time parsing and the On-the-Fly DPS calculation, you must, of course, have your log file turned on with /log.  A batch file that launches the application would also be useful, as invoking it with no parameters will cause it to close. 

 

Usage:

ConsoleParser <logfilepath> <yourcharname> <Show Count Information: 1 | 0> <Showdamagetaken: 0 | 1>

 

Example:

ConsoleParser “C:\program files\Everquest\eqlog_74_Tarissa.txt” Tarissa 0 1

 

The last two variable toggle hit count and defensive information.  0 is off, 1 is on.

Q: How can I see all the data being parsed in Real-Time if EQ is full screen?

 

A: There are two solutions.  The usual method is to have two machines set up.  Share the folder EQ is in, and on the other machine run ConsoleParser with a network path reference.  

 

Ex.  ConsoleParser \\MachineWithEQ\Everquest\eqlog_##_YourName.txt YourName 1

 

Some say you can get a program that allows you to run EQ in a window.  I can’t support that since I hear it’s against the EULA (don’t ask me why, you can alt-tab out of EQ, so it isn’t like it makes EQ easy to hack anyway).  You can then watch the data get collected on the other machine while you play. 

 

Q: Why is this cool?  Why not just download a prettier parser and view the logs off-line?

 

A: There are a lot of parsers out there.  The thing that makes this parser special, however, is the ability for it to activate and deactivate its DPS meter.  Want to know if Ragebringer / Primal is better than Primal / Claw of Lightning?  Equip those weapon weapons and find a mob.  Start fighting.  A DPS field will appear and show your real-time DPS.  Done fighting?  After a specified timeout period, the DPS meter will hide itself and reset, ready to parse the next mob you come across.  Do you want to test out if AC is really doing anything at all?  The DTPS meter (Damage taken per Second) will help determine if that 200 extra AC is really doing anything at all.

 

Q: Are you working on a version of this with a GUI?

 

A: Yes, in fact.  It adds a lot to the complexity and none of the functionality for me right now, so it wasn’t the priority when I started writing the program.  But if more people start using it, I’ll make a graphical interface so there is no need to open up a command shell and launch it.

 

Q: Does this parser work while you’re not playing EQ?

 

A: Yes.  It just won’t update your statistics in real-time, nor will the DPS parser work.
