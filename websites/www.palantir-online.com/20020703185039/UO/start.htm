UO Démarrer

Vos premiers pas dans le monde Ultima Online

Nous passerons rapidement sur la création de votre personnage. Sachez cependant qu'il est important de bien choisir dès le départ vos skills afin de constituer le personnage idéal pour remplir vos ambitions dans le monde de UO. Jetez donc un coup d'oeil sur la description des skills avant de constituer votre personnage.

Vous voilà maintenant dans le monde d'Ultima Online, première chose à faire se familiariser avec votre personnage. Double-cliquez sur votre personnage, vous verrez alors apparaître la fenêtre d'identification de celui-ci. sur la droite une série de boutons :


sur la gauche se trouve la représentation de votre personnage ainsi que votre sac (c'est là que se trouvent les objets que vous transportez). Votre personnage pourra enrichir son équipement au cours du jeu (armures, armes, objets magiques, vêtements, etc...).

En bas se trouve le nom de votre personnage et sa notoriété.
  • Aide : qui vous permettra d'appeler un GM si vous êtes coincé dans le jeu ou pour signaler un Bug ou ce qui vous semble être une injustice. Attention lisez bien les règles en vigueur sur le serveur. En effet, ces serveurs se basent sur des mondes existants pour concevoir l'ambiance du milieu dans lequel vous allez évoluer. Ne demandez pas aux GM de vous créer un cheval rose ou un superbe robot de combat, cela n'est pas RolePlay, pensez plutôt à bien entrer dans la peau de votre personnage.
  • Options : Ici vous allez pouvoir régler les options du jeu : résolution, plein écran, fenêtre, macro (raccourcis...), couleurs de texte, etc...
  • LogOut : sert à vous déconnecter.
  • Journal : Le journal récapitule tout ce que vous venez de faire ou de dire dans le jeu
  • Skill : L'ensemble de vos compétences (pour plus de détails, consultez le chapitre concernant les Skills.
  • Chat : Un World chat sur Ultima , oui oui
  • Peace : vous permet de passer en mode Guerre ou paix pour les combats (Alt+C)
  • Status : Présente les statuts de votre peronnage, là aussi nous y reviendrons


Le dialogue et le contact deux choses primordiales

Discuter avec les personnages.

Vous allez rencontrer deux types de joueurs : les autres joueurs comme vous et des PNJ(Personnages Non Joueurs), les Pnj vont être des marchands, des Healer (soigneurs) ou simplement des habitants des différentes villes, mais dans tous les cas ils vous seront très utiles.

Les marchands : Pour faire affaire avec un marchand, voici les commandes principales. Pour acheter un objet dites le nom du marchand + Buy, celui-ci vous proposera alors une liste d'objets à acheter. Pour Vendre un Objet dites le nom du marchand + Sell, celui-ci vous donnera la liste des objets par lesquels il est intéressé ainsi que le prix, auquel il est prêt à vous les acheter. Vous pouvez aussi déposer des animaux dans une étable pour cela dites le nom du marchand + Stable, le curseur vous permettra alors de désigner l'animal que vous voulez laisser à l'étable. Pour récupérer un animal dites le nom du marchand + Retrieve

Commandes communes : vous pouvez demander à tout PNJ de vous dire le lieu où vous vous trouvez, pour cela dites son nom + where, les PNJ peuvent aussi vous entraîner, pour cela dites leur nom + train, la personne vous dira alors quelles sont les compétences qu'elle peut vous apprendre. Dites alors son nom + train + la compétence (ex: Eric train mining) la personne vous dira alors le prix de son entraînement, posez alors simplement la somme demandée sur le personnage.
