Character Biography Assistant

The Character Biography Assistant program is an aid to creating a biography for a character in EverQuest.

I think this version is finally fully functional. I fixed a couple of completely braindead mistakes on my part for the save/load.

Known issues as of version 1.1:

  1. Minor cosmetic issues. The icons aren't the cool ones I'd like. (Any icon designers out there?) The little graphic on the "About" form falls under this category.
  2. Due to my limited skill with VB's single character handling routines (if it even has any), any line breaks in your History and Goals will get eaten by the web page creation function. You'll just get one big paragraph.
  3. The help file is pretty lousy. *sigh* Someday I might get un-lazy or un-frustrated with the help compilers enough to build a decent one. Bug me about it and I'll either have a nervous breakdown or write one.
  4. The install file is pretty ugly (it's just using the VB wizard for that). I'll look into writing a real install routine. No guarantees though.

If you happen to run across something not listed under known issues, let me know. Heck, you might even make it into the credits...<G>

It requires the VB5 runtime files (Yes, I said VB... This is actually the first program I've ever created using Visual Basic. It shows when you look at the code, especially some that was rewritten from .99 to 1.0.1...) COMCTL32.OCX and MSVBVM50.DLL. The full install file should install everything you need. I think.

If some nice person out there wants to write a much better helpfile, that'd be swell. Not that I actually expect someone to do that (technically, it should be my job, since I wrote the program). If you want to be really nice though, please, be my guest. I'll answer any questions ya have!
