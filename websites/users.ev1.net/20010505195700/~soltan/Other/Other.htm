War of the Elements

Beta version of Magma's RPG created with RPG Maker.  Download and unzip the package into
C:\rpg95\WoE (make a folder for it beforehand)  Then just run "game" like a normal windows application. You may need to copy User32.dll and/or unlha32.dll into your C:\windows\system directory but that's doubtful you'll need it.

The game play is pretty simple, Arrows to move, Enter to do an action (talk, selection, interact) Esc to bring up menu/cancel menu/take back a combat decision.  You can also move with the mouse but the Arrow keys are simpler.
