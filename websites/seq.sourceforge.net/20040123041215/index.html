  If you are registering for the Project SEQ forums...
Due to a cookie conflict with SourceForge, you absolutely MUST be logged out of SourceForge (and it's a good idea to delete your cookies) before trying to register on this forum.

When you register, if you get a "Thanks for registering" and your username is a bunch of garbage, you had yourself logged into SourceForge before trying to register here.

If that happens, you will have to send an email requesting that your account be deleted so you can re-register.

This is not a problem with Project SEQ, but a problem with SourceForge cookie domains that will probably never be corrected.

CVS commit and tarball of ShowEQ 5 Beta 4 Posted by: [Zaphod] on 01-16-2004 @ 11:24 PM
CVS commit of ShowEQ 5 Beta 4 (aka ShowEQ 5.0.0.4),

It works with 12/19/03 EQ Live.

This is a BETA release. The latest stable release remains ShowEQ 4.3.19.

quote:

dohpaZ (01/18/04)
---------------------

  • Updated version to 5.0.0.4
  • More updates to work with 12/19/03 EQLive
  • Fix border cases in SpellShell that would cause ShowEQ to crash.
  • Added a workaround for ISO/ANSI/IEC C++ and C conformance regressions in gcc 3.3.
  • Minor fix in h2info.pl that fixes the comment and operation with certain versions of perl.
  • Made packet handling more robust in the face of corrupt and non-EQ packets that are captured.
  • Support display of a zone's safepoint from the zone packet on the map.
  • Added NetStream classes for handling network byte order data streams.
  • Cleaned up the textual dump of guild names
  • Added GuildShell to track the list of guild members.
  • Added support for LoY guild information capture/display.
  • Made filter2xml.pl more robust in the face of trailing spaces and Windows line termination.
  • Integrated patch #861374 "Fix-three options aren't saved".
  • Integrated patch #864328 "Nedaria's Landing Map".
  • Integrated patch #864329 "Map: JaggedPine touchups".
  • Integrated patch #868227 "Restore light sources".



NOTE: ShowEQ now requires Qt 3.1 or higher.

NOTE: You must use eqstr_us.txt for formatted strings (instead of eqstr_en.txt).

NOTE: You must use spells_us.txt for spell information (instead of spells_en.txt).

NOTE: Don't forget to do a 'make -f Makefile.dist', 'configure', 'make', and last but definitely not least 'make install'.

This release has been tested to compile and run on stock RedHat 9, Fedora Core 1, and Gentoo 1.4.


ShowEQ 5 Beta 4 is should be available on the CVS pserver and the ViewCVS server in the pre_5_0_beta branch within the next few hours. To retrieve the latest beta from CVS use the following command:
code:

$ export CVSROOT=server:anonymous@cvs.seq.sourceforge.net:/cvsroot/seq
$ cvs login
$ cvs co -r pre_5_0_beta showeq


Those who already installed the ShowEQ 5.0.0.3 Beta 3 tarball or retrieved it from CVS should be able to do a CVS update in their showeq directory using the following commands:
code:

$ export CVSROOT=server:anonymous@cvs.seq.sourceforge.net:/cvsroot/seq
$ cvs login
$ cvs update


Because so many of you like them... I've created a tarball for this release. The ShowEQ 5.0.0.4 tarball contains all of the latest changes and may be found here in the ShowEQ Files section.


I've also attached to this post all of BlueAdept's filter files updated to ShowEQ 5 XML format. It contains all the filters from the filters102303.tar.bz2 file on his site converted using the latest filter2xml.pl script. This fixes various things that weren't handled well with the previous version of the script.

Enjoy,
Zaphod (dohpaZ)
