INTRODUCTION

THIS VERSION IS RELEASED TO HELP FIND GAMES THAT ARE COMPATIBLE WITH
XYLOBOT.  YOUR HELP IS GREATLY APPRECIATED IN FINDING ANY GAMES THAT
MAY WORK WITH XYLOBOT.

This is an ALPHA release of Xylobot.  It is not fully functional yet.
This release is intended for TESTING only.  This version is not fully
functional, and displays only a limited subset of the features that
will exist in the final release version.

This version has limited functionality, but also has logging capability
to determine which DirectX API calls are made by a game program.
Xylobot can be tested on various games, and after running the game
the log file will indicate what level of compatibility the game should
have with Xylobot.  Note that even if a game shows it is compatible
based on the log file, certain changes may need to be made to Xylobot
for it to function properly with that game.

By testing Xylobot with various games, users will help find games
that Xylobot can be easily made compatible with.  As soon as Xylobot
is made compatible with at least two games, it can be considered
"generic", and will not infringe on any particular game.


INSTALLATION

Simply unzip the ZIP file into its own directory, usually a directory
called "Xylobot" beneath the "Program Files" directory.  Then run the
Xylobot.exe program.

After running Xylobot, you will see the following text displayed on
the main page of the program:

----------------------------------------------------------------------
When the status bar below displays "Xylobot is Running", simply run your
game.

When you exit the game, return to Xylobot and click on the "Log File"
button on the left.

Look at the log file, and check for the following functions:
1)  DI.GetDeviceData
2)  DDS.Flip or DDS7.Flip

If you find a game that has those functions (both #1 and #2), please
report the game (and copy the log file) to a message on the Xylobot
message board.  There is a link to the Xylobot message boards on the
About page of this program.
----------------------------------------------------------------------
