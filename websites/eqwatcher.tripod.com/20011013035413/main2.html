Welcome to the EQWatcher home page.  Yes it sucks I know.  Deal with it.

EQWatcher is designed to give audio cues for events within EverQuest. In a nutshell, this program watches your eq chat log (eqlog.txt for instance) and interprets what is going on. Additionally, EQWatcher will monitor the eq notes file (notes.txt) for commands directed to it. EQWatcher currently supports up to 50 timers, and 256 triggers, each completely customizable. As a triggered sound EQWatcher is currently capable of playing a WAV file, a CD track, an MP3 (MP3 support is strictly via WinAMP), or Text to Speech (TTS support is strictly via Microsoft Speech API).  EQWatcher is very versatile and anyone can create features such as the included damage calculation.  Please see the Introduction to EQWatcher for this and other information, and please visit the EQWatcher Message Board for news updates, bug reports, and what the people who HAVE used EQWatcher have to say.

Please note that EQWatcher WILL NOT EVER do anything automatically for you within EverQuest.  I get asked about supporting this over and over and the answer is always the same.

Other news, for those having troubles downloading from the main download site, I've put EQWatcher on a mirror site.  Anyone interested in hosting this file please contact me.

Information regarding Windows XP

I have tested EQWatcher with several versions of windows, including Win98, Win2000, and recently Windows XP.  Under Windows 2000 and Windows XP you will want to configure your computer to run BACKGROUND SERVICES efficiently (by default they give much much more CPU time to EverQuest and this will cause sounds to be played very slowly and even break up... in Windows 2000 there's not much hope if your EQWatcher sounds skip though).  In Windows XP: find the system control panel (system properties), and select the Advanced tab.  In the "Performance" frame click Settings, and in Performance Options select the Advanced tab.  Under "Processor Scheduling" click on "Background Services" and click OK.  The process in Windows 2000 is slightly different but I haven't used win2k in a few months, so I can't give detailed instructions.

And as you may or may not know, Windows XP comes with the Microsoft Text-to-Speech engine already installed.  This means that Windows XP users can use the speech capabilities without downloading the SDK from Microsoft.  In current testing, the speech may be slightly broken up.  I will try to do some more testing with this...

EQWatcher Version 1.75 Released

Version 1.75 introduces some great new features to EQWatcher, including Text to Speech.  TTS support requires Microsoft Speech API, but EQWatcher will run perfectly without it as it always has.  To enable speech for EQWatcher you must download and install a 68 meg file from Microsoft (namely the Microsoft Speech SDK).  A script is included that can handle speaking tells and other channels (see "using this script.txt" in the EQWatcher\scripts\channelspeech\ directory).  Another new feature called aliases now allow the user to create their very own EQWatcher commands out of existing ones.   

Many many people are interested in the damage and damage per second scripts, which are extremely easy to use without much knowledge of EQWatcher itself.  Please keep an eye on the message board, and a quick reminder that the command reference should be referred to for any questions relating specific commands before asking anything.  For more information on the damage script please read "using this script.txt" in the EQWatcher\scripts\damage2\ directory.  

Since EQWatcher has gained so much interest recently I haven't submitted news of 1.75 to news sites, until more mirror download sites are created.  If you cannot download from one mirror because its bandwidth limit has been reached, try mirror 2.  The unofficial mirror should also work but hasn't been updated with 1.75 yet.  I can't guarantee the file on the unofficial mirror hasn't been altered, but the person hosting that one can likely be trusted :)

EQWatcher Version 1.5 Released

Version 1.5 brings about the beginning of the EQWatcher user interface and other features to make EQWatcher more user friendly.  One thing helped is the new ease of installation.  EQWatcher attempts to automatically detect appropriate directories, and no longer needs to ask for any of these in most cases.  Another such feature is automatic log file detection -- EQWatcher now automatically finds the current log file in your EQ directory, continually.  Some screenshots of the interface and the new command assistance window (both of which are still being worked on) have been added to the web site.

Many many people are interested in the damage and damage per second scripts, which are extremely easy to use without much knowledge of EQWatcher itself.  Please keep an eye on the message board, and a quick reminder that the command reference should be referred to for any questions relating specific commands before asking anything.  For more information on the damage script please read "using this script.txt" in the EQWatcher\scripts\damage2\ directory.  

Also, please note that one of the main hardware requirements for the sound capabilities of EQWatcher is that your sound card MUST support multiple WaveOut devices.  In general I will guess that any sound card that is PCI (not ISA) and made after 1998, with the exception of extremely low end cards such as Ensoniq AudioPCI, supports this.  I may begin to compile a list of sound cards that have been tested by me and/or EQWatcher users themselves and whether they work or not.

EQWatcher Version 1.18 Released

Version 1.18 sees the introduction of the great new damage script that calculates damage per second, accuracy, and other combat information in realtime.  There are also some important bug fixes.  See the announcements on the message board for more information.  Please see the Command reference for the complete list of commands and default variables before asking if there is a way to make scripts play sounds (or anything else that is listed).  

For more information on the damage script please read "using this script.txt" in the EQWatcher\scripts\damage2\ directory.  It's incredibly simple to use and includes socials to import for anything you might need to do with the script (use EQHotkeys, which is included with EQWatcher).

EULA Information Updated

Someone let me know my EULA information was out of date (the only difference in my quote being part of the old #8 is the new #9), and in my searching I found more useful information on the topic.  Quick reminder that I do not support any action that would violate the EULA, including the Rules of Conduct.  The portions of these rules that deal directly with usage of EQWatcher are as follows:

#5 "You may not modify any part of the EverQuest Client, Server or any part of the EverQuest Web Page located at http://www.everquest.com."

#11 "You will not attempt to interfere with, hack into, or decipher any transmissions to or from the servers running EverQuest."

Again, EQWatcher was written specifically to NOT violate the set rules while offering some audio cues to events in the chat log.  The chat log is not a transmission to or from the servers running EverQuest, nor is the notes file.  EQWatcher does not modify any part of the EverQuest Client, Server, or Web Page.

The EULA portion of the Introduction to EQWatcher has been updated accordingly.
