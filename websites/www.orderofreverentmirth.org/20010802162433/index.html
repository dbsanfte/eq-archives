Welcome to the website!

Hi! I'm your new webmaster Ailean and if you have any suggestions for making the website better, please e-mail them to me.

The roster is now live, this means you can now update your own information, please update your information regularly so that the roster truly reflects the guild members. There is a selection box above the roster table that selects the sort field, (ie. by name, level, class, etc).

To view or update character information just click on the name. Anyone can view the character information screen and the data can be changed on screen, however the database record can only be updated if the correct password is entered. The character information screen contains some data that is not seen in the roster, mainly the comments box and the user links. To enter or edit the user links click on the link just below the links display box.

Due to limitations in bandwidth and server space this site will not be hosting personal web pages or images, the user links have been provided for you to be able to create you own web pages and link to them from your character screen. The screen shots are hosted on a separate ISP so you may find a variation is web performance between the main site and the screenshots section.
