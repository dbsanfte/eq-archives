What is FAQ?
FAQ stands for "Frequently Asked Questions". Because the computer industry can be so complex to many people, we have designed this page with Frequently Asked Questions and our answers so that you may become more familiar with what, how, and why we do what we do.

What is an ISP?
In order to be able to view web pages based on the internet and use programs that interact with the internet, the computer doing such has to be connected to the internet via an ISP (Internet Service Provider). This can be accomplished in many different ways: refer to "What is a T1?"

What is a host and why do I need one?
When you request a website, say www.yahoo.com for example, your web browser sends a request out to your ISP (Internet Service Provider) to find and route the web page information back to you. Once the web page has been found on the internet by your ISP, it is returned to your computer in "code" form which is then translated by your browser to make viewable by you on your computer screen. The code and images that the requested web page requires is stored on a computer accessible 24/7 via the internet, which is called a server. A host is an individual or company that has a combination of dedicated connection(s) and server(s) to store one or (typically) multiple web pages and allow them to be accessible on the internet.

What are Domains and Virtual Domains?
A domain is the top-level of a website name.
For example: www.mydomain.com
A Virtual Domain is a portion of a Domain that is dedicated to a completely separate web page.
For example: www.mydomain.com/myvirtual

What is a T1?
As stated in "What is an ISP", any computer wanting to access the internet has to be connected to an ISP beforehand. This can be accomplished in several different forms. Dial-Up, being the most common for it's inexpensive is not suitable for those requiring fast internet speed. Dial-Up can accomplish a maximum speed of 56k per second, which is brought down even more due to regular phone lines not being able to accomidate speeds any faster. At that speed, for example, you are able to download a full-screen image in approximately 1-5 minutes. For hosting providers, this is not suitable. A T1 is a connection specially installed into qualified locations to transmit data at speeds as high as 1.544mb per second, which is nearly two hundred times faster than the fastest Dial-Up connection.

What is Telnet?
Telnet is a method used by most servers to allow users to perform many advanced functions such as watching a log file, changing file permissions, changing file ownership priviliges, and checking disk quotas.

How do I set up up my mail account(s)?
When Scintillate Services provides you with hosting for your website, you are given a number of email boxes and/or aliases that you can use with your website. In order to view your Scintillate-Mail you need to set up an email program to recognize your new email addresses. The recommended email program is Outlook Express (comes with windows products). When setting up Outlook Express, you will be asked for the following information:

Email Address: mailbox-user@domainname.com or mail-alias@domainname.com
SMTP Mail Server: mail.scintillate.net
POP Mail Server: mail.scintillate.net
POP Username: mailbox-user%domainname.com
POP Password: yourpassword

If you have questions or comments regarding this subject, please continue to our contacts page.

What is a MailBox?
A MailBox is a place on the Scintillate Servers that holds mail for an address of your website. When Scintillate Services provides you with a hosting account, you are automatically given a default postmaster MailBox that can accept email sent in the form of postmaster@yourdomain.com. After mail is sent to a mailbox, it is stored on the Scintillate Servers until you request to read it via your computer's email program (such as Outlook Express).
Top
What is a Mail Alias?
A Mail Alias is similar to a MailBox, except that it is an address that redirects mail to a MailBox. As said above, a MailBox is both an email address and a place on the Scintillate Servers that email can be stored in, wheras a Mail Alias forwards any mail sent to it to the specified MailBox, where it then can be stored on the servers, and wait to be picked up.
