After the recent patch, a peculiar bug has come up for folks using modded uifiles. http://boards.station.sony.com/ubb/everquest/Forum3/HTML/029605.html

If you're crashing when attempting to /bazaar or /trader in the Bazaar, try this if you are using custom XML. Copy the following files into the directory you created under ..\unifiles
gemicons02.tga
window_pieces02.tga
EQUI_TrainWindow.xml
EQUI_SkillsWindow.xml
EQUI.xml
EQUI_BazaarSearchWnd.xml
EQUI_Animations.xml
EQUI_TextEntryWnd.xml
SIDL.xml
EQUI_SocialEditWnd.xml
EQUI_SelectorWnd.xml
EQUI_OptionsWindow.xml
EQUI_BazaarWnd.xml
EQUI_Actions_Window.xml

The patcher only patches updated *.xml and *.tga files to ..\default. If you are using a custom interface, these new files can't be accessed.

Now go fix yo shiet!

:: Tuesday, July 30, 2002 ::
GUI Update!

A few instructions on those still figuring out how to install and update your GUI.

1) Download the interfaces to your computer. Saving them on the desktop makes them easy to find
2) Go into your EQ directory, find the folder named "uifiles"
3) Inside the "uifiles" folder, you'll see a "default" folder. Create a New Folder inside the uifiles folder and name it "Advanced" or "ilikepie"
4) Copy ALL of the files that are in the "default" folder and paste the duplicated files in the new folder
5) Log into EQ and type "/loadskin Advanced" or "ilikepie" (For those that do like pie.)
6) Log to desktop, then come BACK into the game.

Popular UI site:
http://newui.technosapien.net/
