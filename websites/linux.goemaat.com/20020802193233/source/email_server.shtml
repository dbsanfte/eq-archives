Email Server

Description | Quick Start | Properties | FileStorage | Source Code

Description

I was unable to find a free, easy to use SMTP and POP3 server to meet my needs when I purchased the goemaat.com domain, so I created my own. The SMTP server only accepts email for domains which the POP3 server serves email for, it won't forward to other domains. In the future I hope to add support for forwarding messages to the SMTP server, as well as the ability to "plug-in" external classes to handle certain email addresses. This will enable the easy creation of mailing lists, automated processing (for passwords, etc.), or about anything else you can think of.

Quick Start

You must have JDK 1.1 at least installed on your computer, and the current directory must be in your classpath (".").

Download EmailServer.jar. Create a directory "c:\email" and un-jar the file into it (or use WinZip). Then execute "run.bat". Hit Ctrl-C to shutdown the server.

You can now use your favorite email program to send and receive email to "DemoUser@company.com". Just set your POP and SMTP servers to the computer name or IP address the email server is running on. The SMTP server will not forward email, it only accepts email addresses ending with "@company.com", and "DemoUser" is the only user currently setup. The password for DemoUser is "demo".

Run.bat runs the program with the following command:
    java com.goemaat.email.Server

Properties File

The classes in the JAR file must be in the classpath, and the properties file must either be "email.properties" in the directory the program is run from, or specified on the command line as the property "email.properties"
    java -Demail.properties=<filename> com.goemaat.email.Server 

# Properties for my email server program
smtp.port=25
pop.port=110
server.address=company.com
storage.class=com.goemaat.email.store.FileStorage
storage.directory=c:\\email\\data

Comment lines start with a '#', other lines are in the format property=value

smtp.port is the port for the SMTP server to listen for. The standard port for this is 25.

pop.port is the port for the POP server to listen for. The standard port for this is 110.

server.address is the address that will appear in messages (such as the initial connect message) from the servers.

storage.class is the name of the class that will handle storing emails for both the POP3 and SMTP servers. You can make this whatever class you want that implements the com.goemaat.email.store.EmailStorage interface. So far I've only created the com.goemaat.email.store.FileStorage class that stores emails as files and domains as directories, along with special files for a domain list and user lists with their passwords. If you want to store information in a database instead, you just have to create a class that implements EmailStorage and pass it as this parameter.

storage.directory is used only by the com.goemaat.email.store.FileStorage class to specify the directory the data files are stored in.
NOTE: if you are using backslashes ('\') as path separators (Windows machine), you must use the Java character escape, which means each backslash needs to be represented as two as you can see above.

FileStorage Layout

  • Domains.txt - file with one domain name per line. Each domain in this file should have a subdirectory of the same name. All should be in lower case.
  • company.com - the directory with all files for the domain company.com
    • Users.txt - file in each domain directory that has a list of users and their passwords in the format user=password, one per line.
    • DemoUser - directory that will hold all of DemoUser's messages.
      • 20000404-205744-324-0@company.com - message file - straight text with headers and all.
This has the side-effect that you can put any file in the user's directory and it will show up as a message when they check their mail.

Source Code Organization

com.goemaat.email.Server - Class that is run. It loads properties and starts the POP3 and SMTP server threads, as well as setting up the storage.

com.goemaat.email.Domain - Just holds the domain name

com.goemaat.email.Message - Holds message data as well as the delete flag, size, ID, and User it belongs to.

com.goemaat.email.User - Holds user name and domain they belong to.

com.goemaat.email.store.EmailStorage - Interface that must be implemented to create a class that can store Domains, Users, and Messages.

com.goemaat.email.store.FileStorage - Class implementing EmailStorage that stores the domains, users, and emails in the directories mentioned above.

com.goemaat.email.pop.POPServer - This is the thread that listens for POP3 connections and creates POPConnection threads to handle them.

com.goemaat.email.pop.POPServer - This is a thread that is created for each POP3 connection and handles commands sent to it, such as logging in, listing messges, reading messages, and deleting them.

com.goemaat.email.smtp.SMTPServer - This is the thread that listends for SMTP connections and creates SMTPConnection threads to handle them.

com.goemaat.email.smtp.SMTPConnection - This is a thread that is created for each SMTP connection and handles commands sent to it, creating new emails and reporting errors to the SMTP client.
