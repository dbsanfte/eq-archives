Email Server

 When I purchased the "goemaat.com" domain, my hope was to create a web presence where my friends and family could come, and to let me have multiple email addresses. One reason I wanted multiple addresses was so that I could give them out on the web for registering at sites, and not be open to junk email to my main email address. I was unable to find a free email server program that was easy to use and provided all of the functionality I required, so I wrote my own in Java.

With the FileStorage class, it is easy to add users and view their email with just a text editor, it also made testing the server easy. But by implementing an interface for storage, it is easy to change the storage to be in a database or custom file layout, or to encrypt messages.

In the future I hope to add functionality for forwarding messages to the SMTP server, and to make it easy to add your own message handlers for addresses by creating a class and specifying it in the properties file. It should be relatively simple then to create a class for handling mailing lists, and auto-responses for certain addresses or performing pretty much any task.

Email Viewer

 I've noticed at a lot of places, particularly at KVI where I work and at First Union where my fiance works, people have access to the web, but cannot check their home email. I wrote this servlet to enable just that. You enter your user name, password, and server, and you get a list of your emails. You can then delete them (if they are junk, or they are large files and you have a slow connection), read them, and send new messages or replies.

Picture Grabber

 Designing my web site I found it tedious to download lots of images to try out for backgrounds, so I designed this program. It lets you enter a directory and a URL and it downloads any images pointed to by that URL to the directory you specify.

Proxy Server

 The Proxy Server I wrote in Java allows you to provide TCP connections through a firewall. It offers simple encryption as well to prevent unwanted eyes from intercepting your communications. It is based on the fact that you have a server on the outside of the firewall and start the client on the inside. The client listens on whatever ports you wich and forwards each through a connection to the server on the outside to some host and port you specify.

I really wrote it to learn several things in the Java language: Threads, Sockets, Swing (JTable), and extending input and output streams.
