Picture Grabber

Description | Quick Start | Source Code |

Description

If you see a nice picture page on the internet with thumbs and would like to download all of the pictures on it, this program can make it a whole lot simpler. Instead of right-clicking on each link, selecting "Save Target As", waiting for the window to pop up, selecting the directory, and clicking save, you just enter the directory and the URL of the page with the links and all of the pictures are downloaded in the background while you surf. This is really useful for sites that let you download free web images for backgrounds, borders, and bullets.

Quick Start

You need to have at least JDK 1.2, or the Swing 1.1 classes installed for this to work.

Download the file now (27,212 bytes). If you have JDK 1.2 installed, you can double-click on the JAR file to run it, or type "java -jar PictureGrabber.jar". If not, add the jar file to your ClassPath and type "java com.goemaat.grab.GrabPictureFrame".

The program starts out with the download directory set to "d:\pic". This is the directory the picture files will be put into. If you wish to change the directory, enter it into the second text box and hit the "Set Directory" button. The window title should change to indicate the new directory. Enter the URL where the pictures are into the top box and hit the "Store" button to begin retrieving them. This URL must be a file, it can't be a path. For instance, if the web server has pictures in "http://www.goemaat.com/photo/jordan", you must type the actual file that is retrieved, in this case "http://www.goemaat.com/photo/jordan/index.shtml" Good file names to try are "index.html" and "index.shtml". This is due to the way Java constructs relative URLs from a base and will be fixed in a future release. Also note that the "http://" is mandatory.

This is about the first application I wrote in Java and I haven't done much with it in a while. I hope to get the functionality working soon to save the files in a path under the specified directory if the check box is checked, as well as getting the "Store Index" and "Store Many" buttons to work. The Store Index button will take the address of a page that has references to picture indexes instead of pictures themself. "Store Many" is a special feature to store groups of numbered index pages for one site I've found.

Source Code

GrabPictureFrame is the main class for this program. It creates a PictureList object to store the file names, URLs, and directories of the pictures linked to from the page you specify. It then creates GrabThread objects and starts them. They query the PictureList object every 1/2 second until they get a picture from it. When they get a picture, they call a method of the Picture object that opens an HttpURLConnection to the picture and saves the bytes to a file, then they try to grab another picture and go on to waiting another 1/2 second if there is none.

When you click on the Store button, GrabPictureFrame opens an HttpURLConnection to retrieve the page you specify into a StringBuffer. The StringBuffer is then scanned for <A HREF="xxx.xxx/xxx.jpg"> tags with a file name ending in JPG, jpg, JPEG, jpeg, GIF, or gif. If the tag matches those criteria, a Picture object is created with the current directory name and the URL and is added to the PictureList to be retrieved by one of the five GrabThread objects.

All classes are in the package "com.goemaat.grab"

GrabPictureFrame - Main class and frame that is displayed. Handles parsing the pages and creating Picture objects that will be retrieved, as well as the GrabThread objects that will retrieve them.

Picture - Holds the directory that was in effect when the Store button was clicked, the file name, the URL, and a flag from the checkbox. It also has the download() method which pulls the picture to a file.

PictureList - This is basically a wrapper for the Vector class that is thread-safe (I wasn't sure if Vector was or not)

GrabThread - Thread that loops continuously, checking it's PictureList member for new pictures to download every 1/2 second, or immediately after the last download. If it finds a picture, it removes it from the list and calls it's download() method.
