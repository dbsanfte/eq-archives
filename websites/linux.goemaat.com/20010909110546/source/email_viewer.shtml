Email Viewer

Quick Start | Source Code | Run

Quick Start

This works on my computer with Apache 1.3 and Apache JServ 1.0.

Download EmailViewer.jar. Put it in your classpath in your jserv.properties file under wrapper.classpath, or un-jar it into one of your servlet directories. The class is com.goemaat.servlet.email.EmailViewerServlet.

Source Code Organization

Operations work by storing the state of the servlet in the "MODE" parameter when performing operations. If it is blank, the user is supplied with the login screen. Same if the value is "LOGIN". Other values are "LIST" to list messages, "RETR" for retrieving a message, "DELETE" for deleting messages, and "SEND" for creating a new message.

All classes are in the package "com.goemaat.servlet.email"

EmailViewerServlet - Servlet class - handles all requests.

EmailAddress - Used for parsing email addresses various ways, including parsing out address and visible name from email headers, parsing name and domain, and outputting HTML with the "mailto:" tag.

EmailDate - For parsing dates from email headers, as well as formatting for sending messages and for output in short format for lists.

Header - Encapsulating header as name and value

Message - For encapsulating a message and accessing it's body and headers.

POPConnection - For connecting to the server and retrieving the list (headers only) and message bodies, as well as deleting messages.
