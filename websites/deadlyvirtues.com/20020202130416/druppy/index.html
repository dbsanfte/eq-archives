For those of you that don't know, Linux is a powerful, multitasking Operating System. It is freely-distributed and was originally created by Linus Torvalds. Developed under the GNU General Public License, the source code for Linux is available to everyone. As a result of this availability, other  developers have taken the Linux source code and created a variety of different Linux distributions that have slightly different functionality from each other.

Now lets talk about some of the reason why Linux is and always will be superior to any OS put out by MS. First and foremost Linux is free, this means that anyone can afford it even us starving students. Because of the wide variety of people working on it, it has been adapted to most computer platfroms and still delivers a superior interface and more stability than any flavor of Windows/MacOS. Most of the programs you use with Linux/X (X is a GUI for Linux) are free, and you get in the form of source code which means you can edit them to be more specific to your needs (that is if you know C/C++). If you ever need help, and we all do, there are several places you can turn to. The most popular/avaliable place to look for help is documentation by other users, there is a HOWTO directory on sunsite that has extencive information. Once running Linux you will also find that most programs you used in Windows are also availiable for Linux such as different wordproccessors, spredsheets, and web browsers. If this isn't enough info on why Linux is far better than Windows you can read Tracy Reed's "Why Linux Kicks Windows' Ass!" page.
