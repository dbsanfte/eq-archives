Major Linux Distributions

  • The Distribution HOWTO
  • A chart comparing distributions.

  • Redhat Linux comes in a freeware version and in an "Official" version with the commercial Metro-X X-server.
    • You can get Redhat CD-ROMs from a reseller like CheapBytes
    • A list of Redhat packages

  • Debian Linux. I haven't tried Debian recently, so I'll refrain from commenting. I was impressed by the large number of desirable packages available in the .deb format.

  • Slackware: To many people Slackware is Linux. Slackware is missing the sophisticated packaging features of more recent distributions. A large installation with a lot of non-distribution software installed can easily get out of hand. But it's plain vanilla character is still appealing to many.

    • Walnut Creek's Official Slackware CD-ROM.
    • A list of updated Slackware packages.
    • The Slackware SimpleFixes page

  • Where to get it. If you have good ftp access then you can try one of these ftp sites, chosen for having the shortest ping times from cts.com in San Marcos, CA.

    • gatekeeper.dec.com has a Redhat mirror.
    • ftp.cdrom.com has Debian, Slackware and MkLinux mirrors.
    • ftp.drcdrom.com has an MkLinux mirror.
    • ftp.eit.com has a Redhat mirror.
    • ftp.fuller.edu has a Debian mirror.
    • ftp.varesearch.com has a Redhat mirror.
    • ftp.pht.com has Redhat and Slackware mirrors.

    Debian can be installed directly via ftp. You'll have to allocate space on an extra partition for the Redhat and Slackware packages.

  • Yggdrasil sells an 8 disk Linux Internet Archives set with all 3 distributions.
    More up-to-date is Infomagic's 6 disk Developer's Resource set.
    Cheapest of all is Linux Systems Lab's $3 Tri-Linux CD.
  • Caldera OpenLinux is a commercial distribution based on Redhat, with some nice extras.
  • The Linux Shopping Mall
  • Upgrading? Give away your old Linux CDs to a needy person.
