Bienvenue sur le site

des Serviteurs de KARANA

Ce site est le point de ralliement des Serviteurs de KARANA.
Il est testé sur les navigateurs suivant Internet Explorer 6, OPERA 6, Netscape 4.7. Cependant il se peut que la mise en page varie d'un navigateur à l'autre.
Il est conseillé de télécharger la police Tolkien afin d'avoir le meilleur rendu possible du site. Aucune configuration spéciale d'affichage n'est nécessaire.
