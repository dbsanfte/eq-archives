Steave's EQ Maps Page

Well, I was browsing the site logs today and found that a number of people have been looking for this page, only to find that it is not there.  Well, that's because I lost everything on the page during an unfortunate maintenance incident.   By that time, I had quit playing Everquest and thought nothing of it.  Well, it appears that there are still some links to this page, so I will put up what used to be here, plus some.  I also made thumbnails, but left out file sizes for now.

If you get really bored, you can check out my main page which has nothing at all to do with Everquest.  But for now, on with the docs.

Everquest Maps Compilation in Microsoft Word Format (huge: 8.5MB)  Although large, this document is not comprehensive.   Still it's got a lot of material.  Great if you're from Freeport, but very useful otherwise.

I should point out that, other than modifying some of them for easier readability/quality, I had nothing to do with the creation of these maps.  For map sources on the Internet, view the links at the bottom of this page.  Also note that the latest changes, such as Plane of Fear, etc. are not reflected in these maps.
