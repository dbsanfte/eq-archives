Ministry of Steel Help System
  
Please click on the area you wish to find out more information about.
News

This is the news section of the web page, also the front page, you will see this by default each time you access the web page.

 

 

 
 

 

Latest News - This will display the 5 newest news topics.

Active News - This will display all current active news (not yet moved to the news archive).

News Archive - This will show ALL news stored in the News Archives.

Search News - This will allow you to search all active and archived news.

As you can see a various array of search options is available.

Comments - This will allow you to view and add comments about each news topic.

Full Story - If there has been more information about the current news topic posted, this option will show you the full text of the selected news item.
