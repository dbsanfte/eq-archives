DOS COMMAND REFERENCE

The following is a listing of the most useful DOS commands, what the command does, and examples for using the command (sometimes called the syntax). The best way to learn how these commands work and the proper way to issue the commands is to practice. Also, with any command you can type in a /? after the command to get a help screen (for example: ATTRIB /?). Realize that some of these commands will destroy data, so use common sense when practicing. Commands shown here that have a file extension are external commands, those without extensions are internal commands. Don't forget that after you type a command you have to press the ENTER key.

ATTRIB.EXE : Allows you to view or modify a files attributes. DOS keeps track of four attributes for each file, these are HIDDEN, READ-ONLY, SYSTEM, and ARCHIVE. Each attribute is stored as a single bit, so the attribute can be set (on, or a 1 bit) or clear (off, or a 0 bit). The hidden attribute, when set, will prevent a file from showing up on a directory listing. The read-only attribute, when set, will prevent the contents of the file from being modified by the user. The system archive, when set, flags the file as an important system file. The archive attribute, when set, flags the file as being either brand new to the computer, or the contents have been modified. In either case, the file needs to be backed up, back up software uses the archive bit to select which files to back up.

To view the attributes of all files in a directory, type ATTRIB.

To view the attributes of a single file, type ATTRIB followed by the file name.

To modify attributes type ATTRIB followed by the file name followed by which attribute you want to change. Use the letters H, R, S, A as abbreviations for the four attributes, and the + to set and the - to clear. For example: ATTRIB AUTOEXEC.BAT +H.

CHDIR (CD) : Changes which directory you are in. For example: CD DOS will change you from the current directory into a subdirectory called DOS.

CHKDSK : An earlier version of SCANDISK. Doesn't detect/fix as many errors as SCANDISK does. If you have SCANDISK, use it. To use CHKDSK, you need to specify the drive letter of the drive you want to check, for example: CHKDSK C:

CLS : Will clear the screen and put the prompt and cursor into the upper left corner.

COPY : Copies a file. For example: COPY AUTOEXEC.BAT AUTOEXEC.OLD This will copy a file named AUTOEXEC.BAT, creating a new file called AUTOEXEC.OLD that has the same contents as the original.

DATE : Allows you to view or modify the calendar date.

DEFRAG.EXE : This program will defragment a hard or floppy drive. Fragmentation occurs because files normally take up multiple clusters when stored on disks. The FAT file system that DOS uses doesn't make any attempt to store all pieces of the file together. Rather it just finds the first available cluster, uses it, then finds the next available cluster & so on. It doesn't matter if all the clusters are together or not. When they're not together, it takes the drive longer to access the file. DEFRAG finds all the pieces of the file and moves them together. This takes a while to accomplish and puts a little wear & tear on your hard drive, so should only be done about once a month. Fragmentation primarily happens if you delete files and then save new files. So if you don't do that very much, you don't have to run DEFRAG as often.

DELETE (DEL) : Deletes a file. For example: DEL 99BUDGET.XLS will delete the file named 99BUDGET.XLS that is in the same directory that you are currently in.

DELTREE.EXE : This command will delete a specified directory, including all files in the directory, all subdirectories and their files as well. For example: DELTREE C:\GAMES

DISKCOPY.EXE : Used for doing a complete copy of one floppy diskette onto another. Both floppies must be the same capacity; you can't use DISKCOPY to copy the contents of a 1.2MB diskette onto a 1.44MB diskette. You must specify the source drive (the drive that has the diskette that is being copied) and the target drive (the drive that has the diskette that will be copied to). They can be the same drive - they usually will be since most computers have either only one 3-1/2" floppy drive or one 3-1/2" and one 5-1/4" drive. For example: DISKCOPY A: B: will copy the diskette in the A: drive to the diskette in the B: drive. An interesting feature of DISKCOPY: you can use the above command on systems that only have one 3-1/2" floppy drive. It will pretend that the A: drive is the B: drive.

EDIT.COM : This starts the DOS editor, a simple full screen text editor program. Useful for modifying CONFIG.SYS and AUTOEXEC.BAT. If you type in EDIT by itself, the editor will start with a blank screen. If you type in EDIT, followed by a file name, the editor will start and it will bring the file into the editor, allowing you to modify it.

To edit the CONFIG.SYS file, type in EDIT C:\CONFIG.SYS

EXPAND.COM : DOS ships on three floppy disks. The DOS files on these disks are compressed. EXPAND is used to uncompress files. To use this command you must specify the location of the compressed file & it's name, as well as the name and location of the file when it is uncompressed. For example: EXPAND A:\DELTREE.EX_ C:\DOS\DELTREE.EXE

FDISK.EXE : Allows you to partition hard drives. Not floppies, not CDs. The FDISK program is menu based, giving you 4 menu choices: Create partitions, Set active partition, Delete partitions, View partition information. If you have more than one hard drive you'll get a fifth choice: Select which drive to work on. Partitioning is something that is normally done once in a hard drive's life - when the drive is first installed into a computer. Repartitioning a drive that currently holds data will destroy the data. You have been warned!

FORMAT.COM : Allows you to format hard drives and floppy disks. Formatting is what makes the disk space useable. You can also copy the kernel files to the disk being formatted by including the /S switch. This will make the disk bootable.

To format a diskette in the A: drive, type FORMAT A:

To format a diskette in drive A: and make it bootable, type FORMAT A: /S

Like partitioning, formatting destroys data. DOS 6.0 and higher has an UNFORMAT program to help recover from accidental formats.

LABEL : Allows you to create, modify, or delete a volume label.

MEM.EXE : This will display RAM information - how much conventional, reserved and extended memory is installed and available. Use the /C /P switches to see the most useful display: MEM /C /P

MKDIR (MD) : Creates a directory. For example: MD GAMES will create a directory named GAMES, that will be a subdirectory of the directory you're presently in.

MORE.COM : The output from some programs will display more information than will fit onto one screen. The first data that gets displayed disappears off the top of the screen, never to be seen again. To intercept the screen output of a program and have it display one screen at a time, pausing the output until the user presses a key (so they have time to read what is on the screen) use the MORE command. The proper way to use MORE is as follows: TREE | MORE This is the only way DOS can actually run more than one command at a time. In the example, the user wants to run the TREE command. But if there's a lot of directories to be displayed, most of them will scroll off the top of the screen too fast to be read. So you add the | MORE after the TREE. The | symbol is called the pipe, it is on most keyboards as SHIFT \. This pipe redirects the output of one command into the input of a second command. So the output of TREE becomes the input to MORE. And MORE knows how to display one screen of data at a time. A lot of DOS commands can use the /P switch, which is simpler than | MORE but does the same thing.

MOVE.COM : Will move a file from one directory into another. You must specify the files to be moved, and where you want it to be moved to. For example: MOVE LETTER.DOC \WORKFILE will move a file called LETTER.DOC from the current directory into a directory called WORKFILE. The file's name will not be changed. DOS stores extra information about files that you don't normally see. One piece of data stored is something called a directory pointer. This pointer tells DOS which directory a file belongs to. The MOVE command simply changes the directory pointer, the file doesn't get moved to a different place on your hard drive, unless you MOVE the file to a different partition; that will actually be a COPY and then a DELETE.

MSCDEX.EXE : Microsoft CD Extensions. Works in conjunction with your CD-ROM driver to allow DOS to access and use CD-ROM drives. The specific CD-ROM driver must be loaded via the CONFIG.SYS file. You will have an entry something like this:

DEVICEHIGH=C:\CDROM\OAKCD.SYS /d:MSCD001

The /d:MSCD001 is a reference name, it can be whatever you want. The AUTOEXEC.BAT file is where MSCDEX.EXE is loaded, with an entry something like this:

LH C:\MSCDEX.EXE /d:MSCD001

Now, by using the /d:MSCD001 in both places, the actual CD-DRIVER and MSCDEX are linked together.

MSD.EXE : Runs the Microsoft Diagnostic program. This program will display all sorts of useful information about the hardware inside your computer, specifically how DOS is interacting with that hardware. Useful for troubleshooting conflicts or for viewing settings before adding additional pieces of hardware (so you don't create conflicts).

PATH : This command will allow you to set the search path. The search path is the list of directories that COMMAND.COM will search through when looking for an external command. It is common to define the search path via the AUTOEXEC.BAT file. For example: SET PATH=C:\DOS;C:\UTILS;C:\ This will tell COMMAND.COM to search the DOS directory first, then the UTILS directory, and then the root directory.

PROMPT : This command will define how the command prompt looks. The most common way to set the prompt up is to have the path to the directory you are in displayed, and a greater than arrow. The way to set this up is as follows: SET PATH=$p$g Using SET is optional. Commonly placed in AUTOEXEC.BAT, but can be used at any time.

RMDIR (RD) : Removes a directory. The directory must be empty of any files and/or subdirectories, and you must not be in the directory you're trying to remove.

SCANDISK.EXE : SCANDISK is a program that will check a disk for errors in file and directory structure as well as physical defects on the drive being checked. It is good preventative maintenance to run SCANDISK about once a week on your hard drive. You can just type in SCANDISK, or you can also include the drive letter that you want to be checked. For example: SCANDISK C:

SET : Allows you to define an environment variable. To do this, use SET, followed by the variable name, followed by the variable data. For example: SET BLASTER=A220 I5 D3 This will create an environment variable named BLASTER, with the values A220, I5 and D3. Any program can see the contents of the environment variables, and use the data any way it needs to. If you type in SET by itself, the currently defined variables will be displayed. It is common to use the SET command within AUTOEXEC.BAT to set the search path, command prompt, and the temporary directory, among other things.

SETVER.EXE : Some DOS programs were designed to run under a specific version of DOS. If the version on your computer is different, the program won't run. SETVER 'tricks' the program into thinking the version of DOS that is running is the version that the program wants. Loaded into memory at boot up via the CONFIG.SYS file. For example: DEVICE=C:\DOS\SETVER.EXE

SHARE.EXE : Only necessary when your computer is part of a network. This file will prevent two people from accessing the same file at the same time. Loaded into RAM at boot up via the AUTOEXEC.BAT file. For example: LH C:\DOS\SHARE.EXE

SMARTDRV.EXE : Creates a disk cache, which is space in RAM where SMARTDRV can store files that it determines are frequently being requested from the hard drive. Accessing a file from the hard drive is many times slower than accessing the file out of RAM. So using SMARTDRV will speed up a DOS computer. The file is usually loaded into memory during system boot up, by including the following line in the AUTOEXEC.BAT file: C:\DOS\SMARTDRV.EXE Place this line after the line that loads the MSCDEX CD-ROM driver, this way your CD-ROM drive will get cached as well.

SYS.COM : Transfers the system files from the drive specified to the drive specified.
For example: SYS C: A: will transfer the system files from the C: drive to the A: drive (making the diskette in the A: drive bootable).

TIME : Allows you to view or modify the current time.

TREE.COM : The structure of all the directories on a drive is called the tree. The TREE command will allow you to view in a simple graphical manner, the directory structure of the drive you select. For example: TREE will display the tree, beginning with the directory you're currently in and showing all subdirectories. You will not be shown any files, only directories. This command is usually used like this: TREE |MORE

VER : Allows you to view the version of DOS that is running.

VOL : Allows you to view the volume label. A formatted partition is called a volume. A label is a name given to the volume. This label is completely optional, and serves no purpose other than to allow the user to identify a volume.

XCOPY : Does the same as COPY, plus more. Can copy directories as well as files. Use the same syntax as COPY.
