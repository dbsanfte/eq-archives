2c. Can I transfer an existing domain name?
Yes. If you already have a domain name registered with Network Solutions (InterNIC) or any other registrar, we will contact them on your behalf to update your registration. 2g. Can I register a non-U.S. domain name?
We can serve domain names other than .com, .net, or .org, but you will have to register your domain name with the proper local authority within your country. Once your hosting account is activated, we will give you an IP address to use on your domain application form.

Here are the steps for activating a non-U.S. domain:

  1. Check with the agency in your country that manages domain names to obtain their registration procedures. You'll also need the proper form or template required for registration.
  2. Submit your request for a domain account via our online form and use your domain name (e.g., www.yourname.de or www.yourname.es). You'll receive an activation notice that will include an IP address.
  3. Complete the necessary information on your domain form or template; be sure to include the IP address we gave you.
  4. When you register with your regional NIC, supply the names and IP addresses of the nameservers that will service your site. We can give you this information when you place your order.

2h. What is a NIC handle?
A NIC handle is a unique identifier assigned to each domain name record, contact record, and network record in the domain name database. NIC handles are only applicable to domain names registered with Network Solutions (InterNIC). You can use the same NIC handle as the contact for several domains. This way, if you make a change to the NIC handle (i.e., the email address), all domains using that NIC handle will be updated as well.

3. Microsoft® FrontPage 2000

3a. What are FrontPage server extensions?
FrontPage extensions are CGI programs that provide the server side implementation of FrontPage. FrontPage communicates with the extensions via HTTP using a Remote Procedure Call (RPC). When the server sees the "POST" request addressed to the FrontPage server extensions it simply directs the request to the appropriate CGI program. The extensions implement authoring (uploading/downloading documents, ToDo lists), administration (setting end-user, author, and administrator privileges), and dynamic content (browse-time WebBot components).

Without the FrontPage server extensions you will not be able to take advantage of the WebBots that are available through FrontPage. You also cannot author and administer your site using the tools provided as part of the FrontPage Editor/Explorer package.

3d. Are there any publishing limitations with FrontPage?
There are some publishing issues that potential FrontPage users should consider:

  1. Web size -- This seems to be most critical when a "searchable event" is present in the site (Search, Discussion Forum and Table of Contents). The lengthy process of updating the indices for these functions can lead to the connection timing-out (HTTP 100% Error or 'Server has timed-out').
  2. Disk usage -- You may create and publish as many child sites as your disk storage space allows. However, for each child site you publish, FrontPage duplicates certain information into indices and hidden files. This adds 'overhead,' increasing the storage space required for your files. Microsoft's documentation notes, "FrontPage's optional full-text search indexes can take up to the same amount of disk space as your textual content."
  3. Unix server precautions -- If your FrontPage site is housed on our UNIX servers, do NOT use the Edit Access or File Manager features found in your Control Panel to set passwords, limit access, set file permissions or delete directories or files. This should only be done through the options in FrontPage Explorer.

 
Microsoft® FrontPage 2000 top

3e. Can I use both FTP and FrontPage with my site?
Do NOT use regular FTP (such as WS_FTP) to upload files to the server when FrontPage extensions are installed. This may corrupt the extensions, disabling the interactive features available with FrontPage.

Note: The exception to this is when loading custom scripts to the cgi-local directory on your site. Instructions for uploading custom  CGI scripts is included in the notice you will receive when the extensions are installed.

 
Microsoft® FrontPage 2000 top

3f. Are all FrontPage features supported?
Since FrontPage was created for developing Web sites in the Windows environment, some features are only available when the site is hosted on an NT Server. These features include:

  • ActiveX
  • VBScript
  • Active Server Pages
  • ODBC and MSSQL database connections
    (Access, FoxPro)
  • SSL (Secure Socket Layer) Forms Processing (using the WebBot Save Results component)

 
Microsoft® FrontPage 2000 top

3g. What is a WebBot?
WebBots are the mechanism for invoking many of the interactive features built into FrontPage. These features are added to your site through the FrontPage Editor | Insert WebBot component

Some, such as ''Include'' and ''Substitution'' allow elements of your site to be entered once and included in any or all of the pages by inserting the Bot component referencing that element (e.g., a logo or navigation bar). Changes made to the 'master' element are made automatically to any page containing the referencing Bot.

Other Bots, such as Search, Table of Contents and Timestamp, control dynamic browse-time features. These Bots work behind the scenes to keep your site up-to-date for visitors.

The Page Counter Bot, which is available from the FrontPage CD-ROM or Microsoft Web site will not work on our UNIX servers.

For more information on using the Bots, see the documentation provided with FrontPage or contact Microsoft Technical Support.
