Compatibility

Xylobot works with most DirectX compatible games (almost all games that run under MS Windows 95/98/NT/2000 use DirectX).  Check the compatibility page to see if Xylobot works with your game.  If your game isn't listed below, you may want to download the trial edition to test if it works.

Important Note:  Just because a game isn't currently compatible with Xylobot doesn't mean it never will be.  Xylobot is constantly being updated, so check back regularly to see if your favorite game has been made compatible.

If you test Xylobot with a new game, please post the results on the Xylobot Compatibility Testing message board.  If you have a request to make Xylobot compatible with a DirectX game, or a feature request, post it here.

"Partial" compatibility for the "Display" column means that the game is not compatible, but uses the DirectX BLT function, so its possible the game will be made compatible with a future version of Xylobot.

Legal Notice.  Use of Xylobot may violate the EULA for certain games.  Check your game's EULA before using.  Use Xylobot at your own risk.  Xylobot is sold as-is.  Many multiplayer games consider unattended macroing cheating, please check your game rules before running macros unattended.
