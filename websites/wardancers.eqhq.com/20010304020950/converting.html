Converting your Screenshots

When sending in screenshots to the webmaster they should always be sent in either jpg or gif format, this is beacuse jpgs are much smaller in size than the original bmp file created i your EQ directory.
A common problem with this is the conversion of these files. However, the process is actually quite simple.

  • Firstly open the bmp from your EQ directory into a graphics program. ( This can be MS Paint in Win 98 or above)
  • Now simply just click the 'save as' option.
  • When the save window comes up choose and appropriate directory and change the file type pull down menu to .jpg (or JPEG)
  • You should now have a jpg file ready to send to me. On some programs, however, you will be asked to specify the quality of your new jpg just choose a balance between size and quality.

    Sending files
    This is also really easy, you just send them as attachments. Most people will be able to right click on the file and choose the option 'send to' then 'mail recipient.'
    Using MS Outlook Express you can just drag and drop the file onto your email.
    Web based mail users should look for the add attachment link, usually there will be an option to browse for the files you want to attach.
