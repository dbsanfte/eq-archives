Formatage

Cette page vous permet d'uniformiser toutes les pages du site en créant chez vous les pages d'informations ultra vitales pour la guilde. L'intérêt est que lorsque le look du site changera, vous trouverez ici toutes les infos pour refaire vos pages.

Tout d'abord le fond de la page comme vous pouvez voir est blanc. Pour utiliser les mêmes polices vous pourrez utiliser la feuille de style et l'utiliser dans la page que vous créez en mettant 
<link rel="stylesheet" type="text/css" href="page.css"> 
dans la partie head de la page composée. Procédez comme sur cet exemple:

<html>
<head>
<title>Le titre de votre page</title>
<link rel="stylesheet" type="text/css" href="page.css"> 
</head>
<body>
    (Votre page.......)
</body>
</html>

Les propriétés ainsi automatisées sont ainsi:

<p> exemple de texte
<h4> 

exemple de texte
<p class="Titreperso">

exemple de texte

Ensuite il suffira lorsque vous publiez votre page de mettre aussi en ligne le fichier page.css dans le même répertoire que votre page, et voili.
