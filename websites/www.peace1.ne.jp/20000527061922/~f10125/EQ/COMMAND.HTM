COMMANDの使用方法

まず、COMMANDとは何かというと、基本です^^;
と、簡単に済ませてしまうのはなんなので。
COMMANDとは、色々な場面で必要になってくる、基本操作のようなもので、
話したり、戦闘に使ったり、感情表現をしてみたりする場合に使います。
すなわち、覚えておかないと後々苦労するどころか、はっきりいってゲームになりません^^;
ああ、なんていい加減な説明なんだ～。
まぁ、とりあえず覚えた方がいいものです^^;

使い方はいたって簡単、簡潔、ちょ～楽勝！ってなカンジです。
まず、'/'かEnterキーを押すと、下部のMessageWindowに入力するための領域が現れます。
'/'を押した場合は'/'を除いた、'/'からの後ろの部分を、Enterキーを押した場合は'/'を含めて入力すればいいのです。
ただし、そのCOMMANDにTARGETが必要な場合は、先にTARGETを選択してからCOMMANDを入力します。
また、COMMANDに続ける文が必要な場合はCOMMANDと、文の間に必ずスペースを入れましょう。
COMMANDを入力すると、MessageWindowにその結果が報告されますが、英語なので注意。
まぁ、COMMANDの意味を知って入れば、たいして問題はないです。
なので、COMMANDを覚えておきましょう^^;

下記のCOMMAND LISTは必要最低限な物だけを記しています。
もっと詳しい、完全なCOMMAND LISTが必要な方は、 終わりなき旅からさめて に飛んでください。
また、COMMANDは時々PATCHによって変更されたり、増加したりしますので、
EverQuestフォルダ内にあるテキストファイルで、しばしば確認すると、吉です。

COMMAND LIST

会話関連

COMMAND 内容 省略形
/say [text] 自分の周囲に聞こえるように話します。
どの位の範囲まで聞こえるのかは、謎。 		完全に省略可能
/tell [name] [text] 特定のプレイヤーに話しかけます。内緒話しのようなものですが、
Zoneを超えて使用できるので、内緒話しとはちょっと違いますね。 		/t
/gsay [text] Party内会話。Memberだけに聞こえ、周りの人間には聞こえない。
'/tell'のParty版かな？ 		/g
/reply [text] 一番最後に'/tell'してきた人に'/tell'でお返事します。
今は[R]キーを押すと自動的に'/tell'になってちょ～便利。
 		/r
/shout [text] 叫ぶ！叫ぶ！叫べ～！
てなわけで、自分がいるZone全域に渡って叫びます。
緊急時や依頼などで使われます。
 		なし…だと思う
/ooc [text] OutOfCharacterの略。これ自体が省略形。
キャラクターとしてではなく、プレイヤーとして発言します。
Zone内有効。 		なし
/auction [text] Itemなどを競売にかけたり、Tradeしたりします。
Zone内有効。 		/auc

感情表現関連

感情表現はおよそ省略形というのが存在しません。
なので、省略形のコラムのところにはビジュアルがあるかどうか（キャラが感情表現にあった動作をするかどうか）を示します。
なお、感情表現は重要ではないですが、コミュニケーションを図るにあたって、役に立つでしょう。
　
COMMAND 内容 ビジュアル

 		なし

よく使うコマンドです。 		あり

ビジュアルは肩をがっくりするようなものです。 		あり
/nods うなずきます。 なし
/panic 恐慌して悲鳴をあげます。
個人的にはビジュアルがほしかったナリ。 		なし

戦闘中、ヒマになってしまったときにどうぞ（笑 		あり
