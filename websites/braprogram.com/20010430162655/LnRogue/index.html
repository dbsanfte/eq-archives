What is it?
LnRogue is an attempt at writing a nice graphical rogue-like for BeOS. Haven't heard of rogue? Shame on you! rogue was among the first games ever made (oh well, at least it's been around for quite a while..). It's a fantasy-action-RPG, so to speak. Diablo is a rogue-like (if you've heard of that game =), but a 'real' rogue-like is not realtime like Diablo; it's turnbased. That way you can consider your move in peace and quiet, without having to get all stressed up. (You get stressed up anyway, but at least it's not because everything is moving too fast for you to keep up)

Current status
Beta. The basic functions, such as moving around, are done but not much beyond that. You can hack away at orcs and loot their corpses to see if they had any health potions. Consider the current version more a preview-to-alpha than a beta, actually.

Write your own add-ons
Included in the 0.5 zip is example code of how to write your own creatures and objects. Hopefully you can make sense of the code. If you're having trouble, don't hesitate to send me a distress email :)
The example code is the exact code used in the current release of the game, you'll find the orc, the rat and the player all in there somewhere.
Don't forget that you have to copy the compiled add-ons to the add-on folder or the game won't know they're there. (Or you can do what I've done, put a symlink in the add-on folder that points to the compiled add-ons)
[Note: Please don't complain too much about my nasty code, I know it's not optimal =]

Changes
version 0.5 beta 2 (since 0.4):
- A tile can no longer hold more than nine items, this was needed to speed up save and load operations
- Save and load! Use CMD-S and CMD-O to save and load, respectively
- Selectable player class! Ok - you can only select Warrior, but write your own Creature- addon and create your own player class if you want more options :)
- Semi-animation (single frame, doesn't really qualify as an animation does it?) when someone/something is damaged
- Fixed bug when unloading add-ons. This caused crashes when closing the app
- New fancy graphics (partially, anyway) thanks to Oliver Ruehl, hopefully he'll find some time to do the rest of the graphics soon :)
- Doors can be opened
- Multiple levels
- Changed a lot of things internally, old add-ons will have to be modified and recompiled.
- You can name your character

version 0.4:
- Added object Sword
- Player can now wield a weapon
- Released example object and creature add-on code. You can now make your very own creatures and objects :)
- Objects should no longer spawn on doors (but may be dropped there)
- Added the option to display text in other fonts/colors (This is not a user-option, it allows programmers to display important text in an easy to read manner)
- Fixed a LOS bug, the visible area is now symmetric around the player
- Creatures can now face different directions, and the graphics has been altered to show this (True top-down)
- Added support for limited FOV (not used in game at the moment :)
- Changed key-handling, might not work on other keyboards than standard swedish 104-key =) Let me know if you're having trouble with this!

version 0.3:
- Moved the Player and Info windows into the main window. (Have a peek at the new screenshot!)
- Moved objects and monster AI to external files (add-ons). This means that 3rd party creatures and objects are just around the corner. I just want to work on the API some more and then you can create your very own creature and let it loose in the dungeon. Later you will be able to play the creatures you create as well, this is how I intend to implement character classes.
- Modified dungeon creation to allow all types of creatures and objects provided by add-ons to be added in the dungeon.
- Added a new monster, the rat. The rat will not attack with a vengence until damaged (but might accidently attack someone who gets in its way). Will haunt anyone who harms it, including orcs and fellow rats.
- Changed the orc somewhat, made it tougher and less common.
- Added a map. Scroll with the arrow keys, zoom in/out with PGUP and PGDN.
- Changed the apperance of the stats. The background will now turn red as the stat's current value decreases. (And blue if current value is above max)
- Dungeon stats are displayed when starting the game. (Number of creatures and items, dungeon usage)
- It is now possible to drag things to the dungeon view to drop them (bigger target view equals easier to hit :)

version 0.2:
- Fixed a minor graphical glitch when using objects on the ground
- Improved Orc intelligence greatly (need I say pathfinding?)
- Changed Death-condition, now you die when HP is less than 1
- Added B_WILL_ACCEPT_FIRST_CLICK to all windows (by popular demand :)
- Keypresses in the Player and Info windows are routed to the main window, you can control your character at all times.
- Window position/size is saved
