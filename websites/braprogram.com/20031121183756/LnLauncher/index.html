LnLauncher

What is it?
A simple launcher to allow easy access to your favourite apps/files/folders. The (hopefully) intuitive drag-and-drop interface includes features such as 'Open with', automatic lookup of moved apps, commandline arguments and more. Don't like the color? Just drop a color from a colorpicker on the menu to change it!

Usage
- Drag n drop the apps you want in the icon bar
- Click the handle to expand/retract the menu
- Click an icon to launch that app
- Click and drag to rearrange the icons
- Right click and drag the handle to move the icon bar
- Right click an icon to display a menu with options
- Right click the handle to get the Main Options menu
- Drag-n-dropping a file with the secondary mouse button onto an icon makes the launcher try to open the file with that icon
- Drag and drop a color from a color picker onto a menu or handle to change it's color (I use kColor, you can find it at BeBits)

Changes
version 0.8
- Added feature - Tool tips (thanks to Marco Nelissen for providing the very handy bubble helper class. You can find it here)
- Added feature - It is now possible to add a 'Recent apps' menu. This feature requires an external app to provide the list of recent apps, the einsteinium engine to be exact. You'll need DR2, but that will hopefully be released soon enough.
- Fixed bug - 'Open parent folder' didn't work correctly with apps located via the roster

version 0.7
- Fixed bug - Valid links to apps displayed 'broken link' icon
- Changed - Handle now remains docked to the edge of the screen
- Changed - New icon. A big red button.
- Changed - Added some separator items in the main menu
- Added feature - Shutdown menu
- Fixed bug - Folders (and probably other MIME types beginning with application/ as well) weren't always opened correctly
- Added feature - You can drag-n-drop icons from the menu ('DATA' message)

version 0.6

- Change - right clicking an icon now displays a menu with 'Remove', 'Open parent folder' and 'Run with args'
- Change - Droped items are now added to the left of where they were droped
- Added feature - Rescue menu - Restart the Tracker and Deskbar
- Changed - If scroll delay is set to zero, no scroll animation is displayed (used to be 'animate but don't wait after each resize')
- Added feature - Show/Hide replicants menu
- Change - The handle and icons now have separate color settings (Dropping a color on the handle doesn't change the color of the icons and so on). This mean you will LOSE your current color settings!
- Added feature - You can now download the source :)

- Added option - Menu background color
