TetrisDCC


What is TetrisDCC? It's a Tetris variant that can use a DCC command to set up a multiplayer game. It can also be run as a stand alone app, but then you have to use commandline arguments to connect to your friends' games. (Single player mode is also availiable, but at the moment it's more of a time killer than a game :P )

How does it work?
* First, set up a name and a port using TetrisDCCsettings, then do either of these:

1
* Copy TetrisDCC to your Baxter addon directory.
* Then run Baxter and type: /DCC TETRIS a_nick

2
* To play a multiplayer game without using Baxter, on one side run TetrisDCC in a Terminal. A port number is output to the Terminal.
* On the other side, start a Terminal and run TetrisDCC hostname port, using the port specified in the first Terminal.
3
* To run a single player game, just double click TetrisDCC and it'll start running. As mentioned above TetrisDCC isn't a complete single player game at the moment, no hiscore and such. This will be implemented some day.

Controls These are the hardcoded controls:
Arrows left, right and down - Move
Arrow up - Rotate
Space - Drop (please use this, lowers network transfers bigtime :)
