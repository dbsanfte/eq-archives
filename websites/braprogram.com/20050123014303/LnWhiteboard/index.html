LnWhiteboard

What is it?
A whiteboard add-on for Baxter. Two people can paint a picture together.

Current status
Beta.

Usage
Copy the add-on to your Baxter/add-on directory and (re)start Baxter. There should appear a new item in the menu accessed by right-clicking a name in a channel nick list.

Download
Download version 0.1.2 (45k)

You'll also need liblayout, which can be found here
