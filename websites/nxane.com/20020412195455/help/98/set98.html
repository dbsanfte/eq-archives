Windows 98 Set-up

Step 1. Open My Computer.
   
Step 2. Double click on Dial up Networking.
   
Step 3. If the wizard does not automatically start up, double click on Make New Connection. Otherwise jump to step 4.
   
Step 4. In the field "Type a name for the computer you are dialing", please enter IntraConnect. Make sure that modem selected under "Select a device" is the correct modem installed on the computer

Click Next.
   
Step 5. Next, you need to enter the local dial up phone number here. In Area Code, enter the number's area code, and in Phone Number, enter your local access number. 

Click Next.
   
Step 6. The basic setup is complete, click on Finish
   
Step 7. You should now see an "IntraConnect" connectiod in the Dial up Networking window. Right click on Galaxy and select Properties.
   
Step 8. The properties windows should now appear with the following window. Click on the Server Types tab. If it is an earlier version of windows, Server Types, is a button down by configure.
   
Step 9. On the Server types window, please make sure that nothing is checked under Advanced Options. Under Allowed Network Protocols, please make sure that only TCP/IP is checked. Now click on the TCP/IP Settings button.
   
Step 10. On the TCP/IP settings window, go to the area labeled Server Assigned Name Server addresses. Move the selection dot to Specify name server addresses. 

In Primary DNS, please enter the following

140.186.120.99

In Secondary DNS, please enter

140.186.120.98
   
At this point, most Windows 98 user's setup ends. The following is the network setup. This is only needed in certain circumstances, it is provided for informational use only. Please skip to Step 18
   
Step 11. Go back into My Computer and double click on Control Panel.
   
Step 12. Double Click on Network.
   
Step 13. Click on TCP/IP and then click on Properties. The only components that need to be installed are as follows:

Client for Microsoft Networks

Dial up Adapter

TCP/IP

Please make sure that Microsoft Family logon is not there.
   
Step 14. Click OK on this box
   
Step 15. You should now see the following tab, click on WINS Configuration.
   
Step 16. Move the selection to Disable WINS Resolution. Click on the DNS Configuration tab.
   
Step 17. You should now see the following tab. The following are the settings needed here:

Host: <username> 

Domain: intra-connect.net

DNS Server Search Order:

140.186.120.99

140.186.120.98

Domain Suffix Search Order

intra-connect.net

Now Click OK, twice. The computer will now ask to be restarted. Say "yes".
   
Step 18. Now Double Click on the "IntraConnect" Icon located in Dial up Networking. You should see the following screen. Double check the information, then click connect. Within a few seconds, you should be connected.
