This Everquest Website Ring is for all Player Characters who would like to share their Character Websites with others. If you have any questions please contact: Silvermoon_EQ@hotmail.com

Web Rings are a grouping of links that allows a person to search through a specific topic.  To join one of the web rings, there is a hyper link on them that gives you the URL to join.  Information is provided at their site concerning the different topics allowed in order for a website to submit their Home Page. The Information is usually in the form of minimal requirements.  The web ring that is listed in this page is an Everquest related Site Ring that is hosted by Bravenet.

The requirements for this web ring are: 

  1. The site has to be about Everquest, Character Websites in particular, but Guilds and Everquest Resource Websites are welcome to join as well.

  2. No offensive material, which means all age groups can view your site.

  3. The WebRing must be found in an easily reachable location in your website.

If you have suggestions or improvements for this web ring, or if you have any questions that are not answered below, please Email me.  

  1. Make up a password!  Do not use one that you have used in other accounts.  When you sign-up for certain services like a web ring operated by an unknown person, please use a password that is not used in another account.

  2. Site ID is a 'log-in name' to edit your account.  You will be assigned a Site ID when you submit your website to this Web Ring.

  3. When you submit the form to sign up with this Web Ring, you will see a code for you to copy and paste into your HTML. You may not see the graphics yet, until you publish your site on the internet - they are stored on this Web Site - you may right click on the graphics below if you would prefer to keep them in your local directory, then you can change the html code to reflect the local image source. You are also free to design your own graphics for the Web Ring.

     

    For example: instead of the following code: 

    <img src="http://eq_personas.tripod.com/random.jpg" width="75" height="28" alt="Previous Site" border="0" /></a>

    Change the http://eq_personas.tripod.com/random.jpg 

    to

    random.jpg

  4. In the Web Ring (as seen below) change the information "This Site owned by Silvermoon" to reflect your name and email address.

  5. To Join This Web Ring, Click on the Join Button in the Web Ring below!
