GUILD IN-GAME VOICE CHAT
 
After the downloading the program, run the .exe file by double clicking it. It will selfextract and initialize the installation process within a very short time.

This is how the initial screen will look when you have started the roger wilco installation program. Simply press [Next >] to continue the installation process.

The legal mumbo jumbo follows, basically what is says is that the software belongs to resounding, and you are granted permission to use it. Accept the condition by pressing [Yes >]

Now it gets interesting. The default location of the program is now determined. Roger Wilco will normally try to put itself on the C Drive, in the folder program files, creating a subfolder for the resounding programs, and a detail folder for the Roger Wilco program. If you are happy with this, just press [Next >], otherwise press the [Browse...] button, and select an alternate location for the program.

You will now be prompted for a name/folder to be created in the [Start] menu ->Program files section. Either accept the default by pressing [Next >] or supply an alternate folder name, and then press [Next >].

Installation is ready to be performed. This is last chance to cancel the installation, or go back to change anything. Deinstallation can be done at a later date, by entering control panel, add/remove programs, and select the Roger Wilco name. When ready to install, press [Next >]

Installation wil copy several files to your hard disk.

When installation is done, this is the screen you will see. The Roger Wilco program is far from ready to run yet, but it is now available in the Start Menu, and on your desktop.
