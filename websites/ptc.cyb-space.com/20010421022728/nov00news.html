Web Chat will change around 11th December 2000. This should give us back the Netscape users lost due to the upgrade to version 6.0. The new chat will however make people without full duplex sound cards lost.
November 17, 2000
Netscape 6.0 Users: The through web chat, does not work with netscape 6.0. I assume that a solution will be made fairly quickly from the creators of the web chat. I will set the news up as soon as I have a solution for it.
Also this site may look strange the first time you visit it. It seems that netscape 6.0 does not get all the information sorted out before displaying the page the first couple of times. I assume there will be a patch to the version soon. If not I will just have to change the web soite to work around the problem.

Ok. I testet the Everquest client. I see a few minor problems:
1.) There seems to be a memory problem, where the client does not free up around 400k of memory. So if you restart often, without turning off your system, you may experience difficulties.
2.) Memory requirement for the client seems to have increased. So now is a good time to go out and buy that 128Meg Memory block. On my 64Meg system, the client created a 129 Meg swap file so I'd recommend no less than 128 Meg RAM preferably 196 Meg.

Patch is done - all systems go !

Servers playing the elevator games. Well, it shouldn't really come as a surprise. It has allways been this way after a massive patch. And especially after the RoK patch. This time they are also trying to do as much patching as possible for the IoV.
