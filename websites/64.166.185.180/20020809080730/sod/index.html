THE NEW USER INTERFACE HAS ARRIVED!!!

Fully Customizable Interface Changes EQ Forever!

I have placed some photos within this page to show off the new user interface. The first one is of the old interface and the rest will display the new interface, including some shots of the interface after a SKIN has been applied (see below).

To enable the new User Interface, simply type /newui (hit enter) and log completely off to your desktop, then log back in to EQ. You should have enabled the new user interface successfully.

This enables many new features, including the ability to become a merchant in the Bazaar.

To become a merchant, you need to buy a TRADER'S SATCHEL from Merchant Tekrama, (in the Bazaar), which is "no drop" and will hold 10 items. You can offer more than 10 items for sale, by purchasing additional Trader's Satchels.

Place your items for sale within your new Satchel(s) and type /trader (hit enter). The Bazaar Vendor screen will appear, with all of the items contained within your Trader's Satchel(s).

Click on each item and set a price for it. You can do this by clicking on PLATINUM and filling in the number, then hit ACCEPT. You are not done yet... you MUST click SET PRICE after, or it will not be written to your INI file, thus not be correctly priced. If you are successful, the Vendor screen will notify you by displaying the following text...

Item: Shaded Shield price set to (400p), INI file updated.

Once you are finished setting prices for all of the items contained within your Trader's Satchel(s), begin trading by clicking BEGIN TRADER

To double check if you were successful, you can use another new feature which was introduced with the new user interface. Type /bazaar (hit enter) which will bring up the Bazaar Search Window.

This new feature allows you to selectively narrow your search for items very quickly. For example, you can search for an ITEM NAME by typing it within the top-most box and click FIND.

Conversely, you could "search by trader", by pulling down the menu, which contains every trader who has items for sale within the Bazaar.

What I find most useful is to search by TYPE. For example, I am looking for certain spells that I need, so I pull down the menu, SELECT BY TYPE and select SCROLLS and hit FIND. This will display every single spell that is for sale within the Bazaar.

OOoh Oh, I found one! Now how do I find this vendor among the 360 vendors in the Bazaar? Very easy in fact, I just right-click on their NAME, and it turns me to face that vendor. I just walk in that direction and I will find him/her. If there is an obstical in my way, I go around it and right-click on their name again, until I find them.

I have also used this feature to search for only Chest Pieces that a Half Elf Ranger can equip. I can right-click on any item for sale, and it will give me the STATS of that item.

There are some new SKINS that you can download from EQSKINS.COM which will enable you to further customize the new user interface to your liking (see photos).
