Internet Problems:

  • Linksys Router Configurations -or- Game dropping at odd times (Linksys Router is serving the internet)

If you are in a dorm and this is shared by a bunch of people and managed by techy guys, you might be out of luck. Even if the physical router is out of your reach though, as long as they haven't changed the password, we might be able to fix it without getting a bunch of peeps involved.

Ok, I'm not sure how technical you are when it comes to getting in and hacking around and stuff. Here is all the info you need to solve your LD problems.

Here is a link to Sony's website which has a thread that covers the solution. I have copied the important stuff to this email.

First thing you need to do is upgrade the firmware of the router. Use this file from Linksys:

ftp.linksys.com/pub/network/befsr-fw1427.zip

You'll need PKUnzip or WinZip to extract the files to your hard drive and then run the "TFTP.EXE" program.

In the "Server" blank put in "192.168.1.1" (this will be the IP address of your router).

In the "Password" blank put "admin" (no quotes, all lower case)

In the "File" blank put the path to the "Code.Bin" file you extracted from the .ZIP file downloaded.

There is a .PDF file with that .ZIP file that is documentation if you need more explanation.

Once that is done turn off or unplug the router. Count to 10 slow and turn it back on. This will let the new firmware take effect. If you can't do this for some reason, don't worry, it may not be necessary.

Log into your router through Internet Explorer. This can be done by telling it to go to:

192.168.1.1

When you are prompted for a password, leave UserName blank and type in "admin" (all lower case) as the password.

You now should be in the control center of the router. At the top of the screen you should see a couple buttons you can click on labeled, "Setup", "Password", "Status", "DHCP", "Log", "Security", "Help", "Advance". I think, but am not sure, that all these settings are found under "Advanced". Just click on each button until you find them

1) disable the "SPI" security setting (by default it usually is)

2) disable "Block WAN request" (this is usually *enabled*)

3) Goto Port Tiggering (click advance button and find the "forwarding settings" button). There is a blank there, label the 1st entry as Everquest and add 1024 - 9999 in both sets of columns and then apply (your router will reset).

so it will look something like this:

Everquest 1024 9999 1024 9999

I think there is an "Apply" or "Save" button. If so, click it.

4) then reboot your PC's to be on the safe side and to perhaps pickup the new settings but this might not be necessary.
