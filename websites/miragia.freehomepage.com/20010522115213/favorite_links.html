Favorite Sites
Casters Realm One of the most informative and detailed Everquest-related sites out there. There is a wealth of information pertaining to every class, including creation guides, news, and a massive player database.
Official Everquest Site The official Everquest site. You can find server status, scheduled downtime, and other announcements regarding EQ here.
AllaKhazam's Magical Realm Another very detailed site with information about everything EQ. Very detailed information on trade skills, quests, and class information.
EQ Atlas A site filled with maps and zone information. Very useful tool.
Necro.EQclasses (formerly known as EQnecro) The best site out there for necromancer information. Includes a detailed hunting guide for all levels, equipment guide, and a popular message board.
EQdruids No better site out there for druids. Also contains a lot of useful information for anyone involved with EQ. Contains a link to the Druid's Grove message boards as well, a very widely used board by all classes.
