  RTFHTML? Um, no. posted by aablackm on Tue, Jan 29 2002 11:45:24 PM  
With the exception of a very few instances, I can see no reason to have HTML in the general documentation for a program. Especially not for source tarballs, and most especially not in the README file. The README file should contain, at the very least, enough information to get you up and running using the program. If more information (such as screenshots of GUI windows) is needed, the README can have a pointer to online documentation in it. But if you need to see GUI windows in order to get the program working, you probably aren't downloading source tarballs anyway.
