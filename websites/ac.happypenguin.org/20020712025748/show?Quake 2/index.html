  3D support posted by Anonymous on Thu, Mar 21 2002 10:30:04 PM  
Just so everyone knows, there IS support for cards outside of the 3Dfx series. Just make sure you have the support installed first, then run the game with +set vid_ref glx +set gl_driver /usr/lib/libGL.so (or wherever your libGL.so library is). Now you can select "GLX" or "SDL-GLX" if you have SDL installed.
