Greedy

 Version: 0.2.0
Author: Juhamatti Niemelä  
Category: Puzzle Rate this game yourself!   Average of 0 Ratings:(not yet rated)

Simple ncurses puzzle game

Clone of old Amiga game named greed. In greedy you must increase your score by collecting numbers by moving over them. Highlighted numbers show how far you go when you move into that direction. The distance is same than number value in square next to player character. If there are nothing but empty squares around player, game is over.

License: free
