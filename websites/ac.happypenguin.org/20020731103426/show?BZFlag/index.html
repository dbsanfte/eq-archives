BZFlag

 Version: 1.7e6
Author: Tim Riker (maintainer)  
Category: Action Rate this game yourself!   Average of 38 Ratings:

3D networked multiplayer tank battle game

BZFlag is an OpenSource OpenGL 3D networked multiplayer "battlezone capture the flag" tank game for Windows, Linux, Irix, FreeBSD Solaris and Mac OSX. Gameplay really rocks. It's playable on Mesa with diminished and rocks on hardware 3D systems. Game server lists are supported to help you find people to play against.

License: free

Additional System Requirements: BZFlag is an OpenGL application, and as such requires an implementation of OpenGL that works on your system. Mesa is known to work.

  Was one of the greatest, is it still? posted by tomble on Wed, Jun 19 2002 05:14:51 PM  
I stumbled over BZFlag a few years ago (I think it was from a link from Mesa), and totally fell in love with it- and I don't usually like action games such a great deal.

Then some time after, I discovered that the original author had stepped down, and that someone else had taken over from him. The new bloke was saying stuff on the site about how he planned to add all sorts of new features, I can't think of many of them now, but I do remember the idea of being able to carry more than one flag at once!!

The thought that BZFlag would end up being changed in ways like that really made me recoil, it seemed like the bloke had kind of missed what sort of things made the game so great in the first place!! It's not just 3D graphics and being able to shoot other people, there are plenty of games like that, and few measure up.

So, as I'm not sure if I can still get an older copy, can anyone tell me if those sort of things were changed, and if so, when exactly? I don't want to lose the good version I have to an ickier one. Oh, and have the bots improved? I rarely have anyone human to play against.

  Re: Was one of the greatest, is it still posted by TimRiker on Wed, Jun 19 2002 10:31:52 PM
New bloke here.
BZFlag game play is much the same as it ever was. We have improved the network performance and added internet wide server lists so perhaps you can find some human to play against now.
The bots still need work. They are better, but not by much.
I never promised being able to carry more than one flag nor do I think that would be good for the game. It is on the possible to do list though if someone can figure a clean way of implementing it. It's not in the plans for the next revision reworking.
Chris Schoeneman is active in the current CVS version which will have more changes.
All I can say is try the current version and then come back and rank it here. See what you think of the changes.
