XKobo

 Version: 1.11
Author: Akira Higuchi  
Category: Arcade Rate this game yourself!   Average of 28 Ratings:

A scrolling space shooter.

An action game for X11 with many levels. The object is to destroy all the structures on each level by shooting the purple bulb in the center of the structure. Of course, various enemy craft are trying to get you at the same time. This game is strangely addictive.
