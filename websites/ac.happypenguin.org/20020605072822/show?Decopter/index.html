Decopter

 Version: 0.2.3
Author: Jacek Poplawski  
Category: Simulation Rate this game yourself!   Average of 0 Ratings:(not yet rated)

Helicopter Flight Simulation

Decopter is a Helicopter Flight Simulation using OpenGL & SDL.
From the homepage: "In version 0.2.3 you can try ./test_physics and ./test_terrain. I included joystick support and I think it works great. I remember it was possible to play with two joysticks on Atari, maybe that's good idea?"

License: free

Additional System Requirements:

  • SDL
  • SDL_Image
