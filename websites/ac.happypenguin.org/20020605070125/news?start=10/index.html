    MAMECAT 0.44.b38 15 May 2002 09:30
    Category: Game-related Utility
    Avg. Rating:

    Description: A front console/X front end to X-Mame.

    Changelog:
    Version 0.44.b38 released - we proudly present the second public beta of v0.44 ! This is mainly a bug-fix release, but several features have been added as well. The most important changes since v0.44.b24 include:

    • major changes to ROM status parser to fully support FreeBSD !
    • bug-fix: focus problems with search-widget fixed
    • added style: CDE (color)
    • added ASCII export for gamelist
    • bug-fix: incorrect item-selection when right-clicking into gamelist
    • added a sample check dialog (BETA-INFO: incomplete !)
    • replaced the text "Preview not available" with a transparent image and improved look of preview widget's frame
    • bug-fix: automatically refreshing/recreating the catalog and ROM status cache on startup when the xmame version was changed outside qmamecat works fine again
    • when catgen is called from within qmamecat, its output to stdout is not shown any longer; a progress dialog is displayed instead
    • an image is shown in front of the gamename if a preview could not be found (updated after checking the previews and on-the-fly)
