Dreams Eternal

 Version:
Author: Jorrit Tyberghein  
Category: Puzzle Rate this game yourself!   Average of 0 Ratings:(not yet rated)

A first person puzzle solving game built with the Crystal Space engine

Dreams Eternal is an FPS game which tries to concentrate on the storyline instead of just shooting. The goal of the game is also to have a scary athmosphere. Basicly the game will play in the dream world and will concentrate on puzzle solving.

License: free

Additional System Requirements: Crystal Space 0.19
