SDL_Paradroid

 Version: 1.2
Author: David Berry  
Category: Arcade Rate this game yourself!   Average of 1 Ratings:

Port of Paradroid to SDL

What is it - SDL_Para is a port of the Classic C64 game Paradroid. It has been updated to run on most machines without needing a emulator of any sort. I needed a project to work on while learning SDL and programming, and when I had a C64 I couldn't stop playing Paradroid.

License: free

Additional System Requirements: SDL Library 1.2.3
Greater than 8bpp color depth
