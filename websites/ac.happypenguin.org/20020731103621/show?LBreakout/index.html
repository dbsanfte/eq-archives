LBreakout

 Version: 2.2.2
Author: Michael Speck  
Category: Arcade Rate this game yourself!   Average of 20 Ratings:

Breakout-style aracade game in the manner of Arkanoid.

LBreakout is a very polished breakout game with nice graphics, effects and sound. It comes with an integrated, full-featured level editor. It's highly configurable due to an option-packed menu. All options and how to use the editor and of course how to play is explained in a documentation shipped with the package but also available at the home page.

License: free

Additional System Requirements: SDL (any version)
SDL Mixer
PNG (usually included to any distro)
