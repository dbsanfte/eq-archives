Operation Blacksun 2

 Version: alpha 3
Author: Jörg Rüppel  
Category: Action Rate this game yourself!   Average of 0 Ratings:(not yet rated)

Overhead multiplayer spaceshooter

OBS2 is an overhead spaceshooter with support for online multiplayer experience. Currently you can only fly around and shoot others with different weapons, there are no items to collect and no other goals to achieve. I'd be happy to see someone opening a dedicated server, so other people get the chance to play it.

License: unknown

Additional System Requirements: Allegro 4.0.x
