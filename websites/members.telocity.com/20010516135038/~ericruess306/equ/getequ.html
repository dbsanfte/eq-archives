    EQu is an EverQuest utility that allows you simple modification of your eqcleint.ini data, server status monitor, and in development a log parser and a picture viewer for viewing your screenshots.

    EQu's Client Editor has one of the most intuitive interfaces to the eqclient.ini file around. There is little guess work as to what your text colors will look like in EverQuest when you modify them with EQu's Client Editor. You can see your text floating over actual EverQuest textures while you edit it, and you can import your own imagry to be displayed behind your text if you want to. Choose your colors with the standard color picker, or edit RGB values directly if you wish. You can view your text against 2 different backgrounds at a time, to be sure your color combinations will be visible whether you're in a dark Kunark jungle, or the brigt snows fields of Velious.

    EQu's Server Status program shows you average server populations, ping times to world servers, player density information, which server is the most crowded and which is the least crowded, and allows you to set an alarm for up to 5 seperate server states.

    Because EverQuest continually changes, EQu does too. EQu has a patching system similar to what we're used to using with EverQuest, to keep itself abreast of the latest eqcleint.ini changes, and to allow continued development of the other things (such as the log parser and server status programs) without the user having to constantly hunt down and check the EQu website for downloads. Keeping EQu current is simple - just choose to patch from the menu in EQu, and the new files are downloaded for you.

    EQu is free. It's written simply as a tool to aid the my fellow EQ addicts, and to entertain my programming hobby. Hundreds if not thousands of EQ players have downloaded it and use it regularly to monitor server status and change their client settings. I'm proud of how far this program has come since it was a simple little eqclient.ini editor... it's had it's ups and downs, and a few nasty bugs with the patcher and an ISP switch, but all in all it's doing quite well now and has been pleasently refined into something that represents and actual program =) I invite anyone who plays EverQuest to download EQu and enjoy.
