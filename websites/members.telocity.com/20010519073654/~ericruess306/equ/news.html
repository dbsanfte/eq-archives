EQu News & Development Log

Saturday - 4/28/01
    3:15pm MST

      If you don't have EQu installed on your PC right now, you can forget the following instructions - the install package you will download already has the update being described below. Those of you who were EQu users prior to the ISP switch (about April 6th 2001) need to do the following:

    • Download the new patcher (You want to "save it to disk" - do NOT choose to open the file from it's current location).

    • When prompted, choose to save the file to your EQu folder (which for most people will be c:\program files\equ, unless you chose something different when you first installed EQu). When it asks if you want to overwrite the existing EQuPatchere.exe file that already exists there, say Yes.

    • Once the download is complete, run EQu and then patch as you normally would. Or, in Windows Explorer find your EQu folder and doulbe-click the EQuPatcher.exe file. Once EQu's patch process is complete, you are done updating. Watch the patch message for changes.
