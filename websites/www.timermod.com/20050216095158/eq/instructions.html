UI Timer
URL: http://www.horizonsoutpost.com/eq/timer.asp
Author: Arista (arista at horizonsoutpost dot com)
In your EverQuest\uifiles directory, do one of the following:
  • If you currently have no UI mods installed, create a new folder named "timer" (or whatever you want).
  • If you want to use an existing UI mod, choose the folder containing your UI mod files. The timer will replace the window you selected.
    • Remove any previous version of the timer, then place the TGA and XML files into the above directory. The timer requires only these two files.
    Log into EverQuest, and type in the following:
    /load timer 1
    Substitute timer with your folder name, if different. The parameter 1 is important for preserving your settings.
    The timer is now ready to use. To show/hide the window, press the hot key mapped to the window used. To move the timer window, click on the edge of the window and drag it. See the FAQ for more information on how to use the timer.
    To download a different configuration, or to generate your own custom configuration, visit the timer home page:
    http://www.horizonsoutpost.com/eq/timer.asp
