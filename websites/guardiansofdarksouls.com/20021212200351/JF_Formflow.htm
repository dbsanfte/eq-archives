FormFlow 99 – The Next Generation of Forms Processing

JetForm provides businesses with powerful software solutions that fully automate the design, filling and routing of forms across business processes and large numbers of end users.

FormFlow 99 is an electronic forms solution that provides unprecedented application interoperability, zero administration capabilities, process and routing security, integration capabilities and application functionality. FormFlow 99 opens commercial and business processes for large-scale Web and intranet processing, and enables you to take full advantage of thin-client, Web-based architectures and component-based distributed computing.

FormFlow 99 is based on five key elements.

ZERO ADMINISTRATION
 FormFlow 99 reduces the total cost of ownership by providing true zero administration, allowing the distribution and deployment of forms to any desktop with virtually no administrative effort required by the user or the organization.

FLEXIBILITY
 Businesses need to deploy e-forms using Web-based technology, thin-client architectures, in standalone mode, or a LAN-based environment. FormFlow 99 provides a flexible base from which to select one or many different deployment options.

SCALABILITY
 FormFlow provides a scaleable architecture, enabling you to add or remove forms functionality, integrate other environments in the forms solution, or add more users with no need for additional deployment work.

OPEN ARCHITECTURE
 FormFlow 99 is based on open, vendor-independent standards. This ensures that your forms solutions will expand with your needs and integrate easily with non-JetForm functionality and/or products.

LEVERAGE EXISTING INFRASTRUCTURES
 Businesses make significant investments in their technology and computing infrastructures. FormFlow 99 enhances the value of these technologies by leverage the infrastructure to provide total forms solutions, including databases, messaging systems, intranet, extranet and Web-based architectures.

Other FormFlow 99 Features

DIGITAL AND DIGITIZED SIGNATURE SUPPORT
 Form designers can secure the captured form data by adding digital signatures to the form. Through the use of industry-standard digital certificates (Web-based or Entrust certificates), form data is locked so that tampering can be detected.

INTEGRATION WITH JETFORM INTEMPO™
 FormFlow 99 users can initiate and participate in InTempo enterprise workflows. Forms provide the best metaphor for process-based information and the combination of InTempo and FormFlow 99 create a powerful combination for large-scale process-automation applications.

INTEGRATION WITH JETFORM CENTRAL™
 FormFlow 99 applications can submit DAT files to JetForm Central, the industrial-caliber output-management solution that provides printing, faxing, e-mailing, and database update functions.

DATABASE CONNECTIVITY AND BINDING
 Based on OLE DB / ADO – Microsoft’s next-generation data access specification – FormFlow 99 allows data-access to a much broader set of data, than was previously possible. Data repositories such as non-relational database systems including mainframe ISAM/VSAM and hierarchical databases; e-mail and file system stores; text, graphical and geographical data as well as the classic relational database stores via ODBC, are all accessible from a FormFlow 99 form.

BASED ON INDUSTRY STANDARD COMPONENT OBJECT MODELS
FormFlow 99 is based on standard component object models. This allows third-party objects to be integrated into the form with standard form objects, providing for a richer end-user experience. These rich forms can then be deployed into a variety of environments – Web browsers, VB custom applications, Microsoft Office 97 applications, etc.

POWER FOR FORM DESIGNER, EASE FOR FORM USER

The FormFlow 99 Form Designer addresses the needs of professional form designers through a complete toolset for graphically laying out forms and quickly and easily adding intelligence to those forms. In addition, the Form Designer supports the integration of third-party controls without additional programming. This enables the form designer to quickly and easily include new functionality, without mastering new programming tools.

FormFlow 99 Form Designer includes support for tabbing order, calculations (including conditional tests), validations, lookup lists, buttons, and graphics. It allows form designers to accurately reproduce their existing paper forms in an electronic form, ready for distribution through their LANs, WANs or intranets.

FormFlow 99 supports Microsoft’s 32-bit client operating systems: Windows 95, Windows 98, and Windows NT 4. FormFlow supports the development and deployment of traditional client/server e-forms applications that support these platforms using a remarkably thin client. In addition, FormFlow 99 also supports an ultra-thin browser/server deployment model by integrating completely with popular Web browsers.

Users of FormFlow 99 can locate forms using either the Web or local storage, and open those forms inside Web browsers, such as Microsoft Internet Explorer or Netscape Navigator. Users can print the forms, with or without the entered data, at their local or networked printer. Users can also save the data they enter into the form or submit the data to a Web server using standard methods.

System Requirements
TO RUN FORMFLOW 99 YOU REQUIRE:
 

  • Pentium® processor with a minimum of 16Mb of RAM (166 MhZ with 32Mb of RAM recommended.)

  • 21Mb hard disk space available.

  • Microsoft Windows 95, Windows 98 or Microsoft Windows NT® 4.0

  • Color graphics monitor with a video card supported by Microsoft Windows 95, Windows 98 or Windows NT

TO DEPLOY YOUR FORMS IN A WEB OR LAN ENVIRONMENT:
 Install FormFlow 99 Web Server Components on a Web or file server with 5Mb of free space on the hard disk.

FORM FILLING ENVIRONMENTS:
 End users require an application on their computer to fill, print and route forms. What they use depends on the method you choose to deploy your FormFlow 99 forms.

If your forms are deployed on a Web server, users require Internet browser software. FormFlow 99 supports:
 
  • Microsoft Internet Explorer 3.02 with Authenticode™
  • Microsoft Internet Explorer 4.0
  • Netscape Navigator™ 4.04, with the NCompass ScriptActive™ 2.9.0.1 or NCompass ScriptActive version 2.9.0.4**
** Included with the product. If your forms are deployed on a LAN server or locally, users can use FormFlow 99 Filler.

If you integrate your forms in an ActiveX-compatible hosting environment such as a custom Microsoft Visual Basic application or Microsoft Outlook, users require the applicable software hosting environment on their workstations.
