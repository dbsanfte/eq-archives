JetForm - Design™

GRAPHICAL DEVELOPMENT TOOL FOR E-FORM CREATION AND AUTOMATION


JetForm Design is a graphical development tool whose advanced technology enables you to create exact electronic replicas of your paper forms — quickly and easily. JetForm Design’s development tools allow designers to create multi-page and multi-part forms of up to 99 pages — any size, portrait or landscape. The AutoTrace feature allows for automatic tracing of scanned-in paper forms.

JetForm Design includes extensive graphical design tools. Duplicate your paper forms easily with design tools such as lines, boxes, arcs, circles (of any width or thickness), text and text formatting, tables, check boxes, radio buttons and data fields. User-defined grids enable the precise placement of graphics and text. As well, most popular graphic formats are supported including PCX, TIFF, WMF, PostScript, BMP and GIF. Additional features include: full font support, shaded text, rotated text, variable leading, embedded logos and custom color dll (dynamic link library).

Now, JetForm Design allows you to create forms for use on handheld PCs — ideal for mobile computing professionals who need to capture data while on the road.

EXTENSIVE FORMS FILL-IN CAPABILITIES
Designers can include calculations in their forms to automatically perform math functions. Functions include arithmetic, date/time, financial and conditional logic (if/then/else). Other fill-in capabilities include:
 

  • Support for setting other field attributes based on information in current field

  • Extensive validation rules and error checking including pop-up help boxes

  • Choice lists for automatic data entry

  • Serialization for numeric formats with auto increments

  • Expandable fields for database lookup, numeric, signature and text fields. The field expands or shrinks, both for display and print, to accommodate the amount of text entered in the field.

POWERFUL, FLEXIBLE OUTPUT
Forms can be used with JetForm Central™ to create professional-looking output from any line-of-business application. JetForm Central’s native support for over 40 printers provides print speed up to two times faster than standard operating system print managers.

SET UP WORKFLOW SOLUTIONS USING YOUR EXISTING E-MAIL SYSTEM
Designers can set up forms to be automatically routed once they are filled in. Multiple views allow designers to create different views of a form for each user in a route and specify which data each user will be able to see, fill-in or print. Forms can be signed with digital signature encryption.

ADMINISTRATIVE TOOLS FOR EFFICIENT FORMS MANAGEMENT
The Forms Dictionary enables users to retrieve and store entire forms, subforms, form object groups and data elements, and specify which individuals/departments can use/modify which forms.

ADVANCED PROGRAMMING FEATURES
Programming features such as the Form Map, a graphical interface to manage and organize subforms and form sets, allow designers to organize a form into parts that can conditionally appear as data is entered from a JetForm Filler Pro ™ user. Other features, like Basic Script support, provide the ability to create custom macros. The OLE function enables forms to include ActiveX Controls and, with ActiveX Controls, you can integrate non-form components.

MESSAGING
JetForm Design offers full Lotus Notes ® support, including ODBC access to Lotus Notes databases and field exchange in Lotus Notes for sending, receiving and bi-directional communication. Because of JetForm Design’s support for Microsoft ® Exchange, designers can nominate form fields to appear as MS Exchange Custom Properties and can then use the MS Exchange Viewer to select, filter, sort and manage displayed forms.

ADDITIONAL SUPPORT

  • Bar codes can be generated based on data input. Supports most common bar code formats including UPC-A 2 of 5, 3 of 9, Code 128, Codabar, EAN 8 and 13, and postal. Now provides support for the PDF417 two-dimensional bar code. This allows the encoding of larger quantities of information than with one-dimensional bar codes.

  • Support for DDE and OLE 2.0.

  • ODBC-compliant drivers for the following databases: dBASE, Clipper, Paradox, ORACLE, NetWare SQL, Btrieve, SQL Server, DB2, Sybase, Ingres, INFORMIX, XDB, Excel, PROGRESS, OS/2 DBM, SQL Base.

  • Languages: English, French, German, Swedish, Spanish, Italian, Finnish, Norwegian, Danish, Brazilian, Portuguese, Czech, Polish, Hungarian, Russian, simplified Chinese, traditional Chinese, Korean and Japanese.

SYSTEM REQUIREMENTS

  • For 4.X: IBM PC or compatible with an 80486/Pentium® processor. A minimum of 8MB of RAM. Hard disk with 12MB free space. Graphics display monitor. Mouse or other pointing device. MS-DOS 4.01 or later. MS-Windows 95 or NT 4.0. All standard MS-Windows printers supported.
  • For 5.X: IBM PC or compatible with a 80486/Pentium® processor. A minimum of 32MB of RAM. Hard disk with 20-30MB free space. Graphics display monitor. Mouse or other pointing device. MS-DOS 4.01 or later. MS-Windows 95 or NT 4.0. All standard MS-Windows printers supported.
