Update
Posted Thursday, February 1, 2001 by Puen NobleHeart
Greetings!

EU has had a few changes in the past week. For starters, there is now a message board being hosted through ezboard. I know a lot of EQ sites use EZboard messageboards and to keep things as easy on you as I can, I have chosen to go the same route.

Another addition is the start of the Character Profile section. This is a database driven ASP page. You can take a look and see the information that is provided to you so far for each character that decides to add their info into our database.

The Character Profile section has a few features still to come. They include - the ability for people to add their characters automactically, the ability for that person to modify their data, and there will be search features enabled so you can find all the members of a specific guild, all of a specific class or race on your server, or list all of the people between certain levels, and much more.

I am still deciding on if I will add a chat room. Please post your comments on the SITE ENHANCEMENTS section of the message board.

I am also working on an Item/Equipment database that will have all of the in-game items and pricing guide. I will later tie this in with the Character Profile database so you can click on an item from within the character profile section and it will open a seperate window with that items stats.

Thanks for visiting EU!

- Admin
