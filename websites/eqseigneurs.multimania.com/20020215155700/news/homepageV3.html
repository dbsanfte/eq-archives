V3.0 de la homepage

Pourquoi une nouvelle homepage ?
Tout d'abord, l'ancienne version ("v2.0") était difficile à maintenir. L'emploi de Templates nous obligeait à utiliser Dreamweaver, tool en fin de compte pas si génial que ça! Le code HTML généré étant de mauvaise qualité...
Cette homepage contient donc des frames à la place des Templates. Cela non seulement facilite la navigation, mais également rend plus simples les pages HTML (moins de code).
Recommendations "techniques"
Malheureusement, l'affichage de cette nouvelle homepage n'est pas identique sur tous les browsers. En particulier Netscape (en tout cas dans sa version 4.x) n'interprète pas correctement les CSS (Cascading Style Sheet) V2.0.
Personnellement, je recommande Opera. Ce browser est le seul (à ma connaissance) qui respecte intégralement toutes les recommendations du W3C, l'organisme qui définit les normes pour l'HTML, les CSS, etc.
Si cependant vous utilisez Internet Explorer de Micro$oft (bouh), vous ne devriez avoir aucun problème. Je ne sais pas ce qu'il en est de la dernière version (6.1) de Netscape...
