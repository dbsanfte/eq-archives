1. WAS IST MGREP
================
	
 MGrep ist ein Programm welches Dateien mit einer auswählbaren
 Dateierweiterung auf einen Suchtext durchsucht. MGrep ist aber
 gleichzeitig auch mein erster Versuch überhaupt irgendwelche
 Software für den IC35 zu schreiben. Daher kann es sein das es
 an manchen Stellen noch klemmt.
 MGrep ist freeware oder noch besser: 
 MGrep ist Macht-Doch-Damit-Was-Ihr-Wollt[TM] Software ;-)
 Wer interesse an dem Code hat kann ihn bei mir unter der oben
 aufgeführten EMail adresse anfordern.
 Ich übernehme keine Garantie das MGrep immer und unter allen
 Umständen funktioniert und kann auch Haftung für eventuell durch
 die Benutzung von MGrep entstehende Schäden an der Hardware oder
 dem Datenbestand des IC35 übernehmen. 


2. INSTALLATION
===============

 MGrep wird wie viele andere Programme für den IC35 auch über den
 IC35 Manager installiert. Zusätzliche Schritte sind nicht notwändig.
 Weitere Information zur Installation von Software sind dem 
 Benutzerhandbuch zum IC35 Manager zu entnehmen.


3. WIE BENUTZT MAN MGREP
========================

 Nach dem das Programm installiert wurde, kann es ganz normal über
 das Menü Anwendungen im Startbildschirm des IC35 gestartet werden.
 Sämtliche Funktionen von MGrep werden über das Menü ausgelöst.
 Das Menü im einzelnen:
 
 Grep - Suchen:
  Nach Eingabe eines Suchtextes wird die aktuelle MMCard auf diesen
  Text durchsucht

 Grep - Erweiterung:
  Über diese Option kann anhand der Dateierweiterung festleget werden 
  welche Dateien untersucht werden sollen. Die Dateierweiterung muss
  ohne führen Punkt und mit entsprechender Gross/Kleinschreibung
  eingegeben werden
 
 Grep - Beenden:
  Beendet das Programm

 MMCard - Auswählen:
  Legt die aktuelle MMCard fest. Bevor eine MMCard durchsucht werden
  kann muss hier die aktuelle Karte festgelegt werden.
