   Development: GameBoy 
 

Gameboy Softwareentwicklung im Dialog

Q: Hae? Software für den GameBoy schreiben? Wie geht denn das?
A: Nun, das ist eigentlich garnicht so schwer. Alles was man dazu braucht gibt es im Internet. Da wäre zum beispiel der Assembler RGBDS den es bei http://www.otakunozoku.com/ gibt oder das Gambe Boy Development Kit GBDK - ein C Compiler für den Gameboy - bei http://gbdk.sourceforge.net/ und eine Menge anderer Tools direkt beim Gameboy Develpment Webring.
Für die ganz eiligen habe ich ein Set von Tools zusammengestellt. Es beinhaltet das GBDK, den RGBDS sowie das Assembler Studio, den GameBoy Code Editor, einen Tile und einen Map Editor.
 
Q: Assembler? C Compiler? Das hoert sich ja an als waere der GameBoy ein richtiger Computer. Was steckt da eigentlich an Hardware dring?
A: Das Herz des GameBoys ist ein Z80 Prozessor mit all seinen Vor- und Nachteilen. So einfach Z80 Assembler auch ist, so verzwickt ist das Speichermanagement wegen der schmalen Busbreite. Ansonsten erinnert der GameBoy sehr an eine gewöhnliche Spielkonsole. Er bietet spezielle Video RAM Bänke, Sprite Speicher, Off Screen Buffering und vieles mehr was das Erstellen von Spielen erleichtert.
 
Q: Alles schön und gut. Und wie kann ich meine Spiele ausprobieren?
A: Eine Möglichkeit Cross Platform Entwicklungen auszuprobieren ist das Ausführen der Software in einem entsprechender Emulator. Gameboy Emulatoren gibt es wie Sand am Meer. Natürlich kann kein Emulator echte Hardware ersetzen und daher kann mittels des GB X-Changers Flashram Module beschreiben. In Deutschland kann man den X-Changer sowie entsprechende Speichermodule über HongKongFun.de beziehen.
 
Q: Wow. Und? Wie sieht das traditionelle HalloWelt für den GameBoy aus?
A: Hier ist es: HalloWelt.asm. Der Source Code ist umfangreich kommentiert. Zusätzlich wird der GameBoy Standard Header, eine aktuelle Hardware Definition, eine von mir modifizierte Memory Library und der IBM PC Zeichensatz benötigt.
