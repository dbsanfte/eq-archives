   Development: IC35 
 
Tools und Informationen

Das Herz des IC35 ist ein Z80 kompatibler Prozessor von Siemens. Demnach dürfte es nicht sonderlich schwierig sein dafür Software zu entwickeln. Um das ganze noch einfache zu Machen bietet Siemens ein SDK an welches in MS Visual C++ integriert werden kann. Kompiliert man den Quellcode unter Visual C++ wird er automatisch an einen Emulator gebunden. Leider unterscheiden sich Emulator und Hardware in einigen Punkten was das Verhalten angeht. Wenn mir mal langweilig ist schreibe ich das alles mal auf und stelle es hier ins Netz.

Hier schonmal ein kleiner Ausblick:

  • Im Emulator sind Variablen initial mit 0 gefuellt, im IC35 dagegen nicht. Dadurch entstehen die seltsamsten Effekte. Verwendent man beispielsweise einen Array als Nullterminierten String steht natuerlich nur Muell drin und eine Null die den Text terminiert gibt es auch nicht. Lösung: Arrays mit 0 fuellen. 
    		memset(cArray,0,sizeof(cArray));
  • Der Emulator verwendet die Funktion cMain als einsprungpunkt in die Applikation. Der IC35 benutzt dagegen die erstbeste Funktion aus der ersten Speicherbank. Hat man Hilfsfunktion wie z.B. das Löschen des Bildschirms ueber der Funktion cMain stehen, startet der IC35, löscht den Bildschirm und verabschiedet sich dann wieder.

 Eigene Entwicklungen: MGrep für den IC35

MGrep durchsucht alle Dateien bzw. Dateien mit bestimmten Erweiterugen einer Multi Media Card auf ein vom Benutzer festgelegtes Textmuster. MGrep ist die erste nicht auf der Siemensseite veröffentliche Anwendung für den IC35 Organizer.

In der aktuellen Version läuft MGrep stabil, es ist aber trozdem ratsam vor der Installation ein Backup der Daten anzufertigen. Weiterführende Informationen zum Thema Software Installation und Backup der IC35 Daten sind Bedienungsanleitung des IC35 zu entnehmen.
