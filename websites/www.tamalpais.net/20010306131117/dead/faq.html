What's the deal with...
  • Getting Dead shows over the Web?
       Nowadays, more and more shows are becoming available to download over the Web in many forms. The most common way to do this is through RealAudio files (.RA), which are streaming files that can be played live on your computer as they are downloaded. You can listen to RealAudio files with the RealPlayer. Any live music over the Web probably uses RealAudio technology.
      The newest (and best) form of Web audio is the MPEG file, the latest version of which is called the MP3. This technology allows a sound file of CD quality to be compressed into a fairly small package, which can be downloaded over the Web. It still takes a while to download it, but the end result is CD-quality sound, which you can listen to using a MPEG player like WinAmp. MP3 technology makes it possible for tapers to trade shows online.
      You can find out more about web audio technology, including links to Grateful Dead audio, on the download link page on DeadWeb.

  • DAT and CD-R machines?
      Because DAT machines and CDs are digital as opposed to analog, when you copy a show it loses no sound quality (as opposed to tapes). It's possible to trade shows on CD using a CD burner, which can be stand-alone machines or internal computer drives. For more information on DATs, try the DAT-Heads page... the CD-Recordable FAQ can tell you everything you need to know about transferring shows to CD.
