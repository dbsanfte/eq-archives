Bulletin Board Help

Let's start with the disclaimer: Though it seems like a long time since I first told everyone that I would make a bulletin board feature for the Farm site, it's still in its testing stages. This help page will attempt to describe how I want this thing to work, not how it actually does work. If you notice major differences between what I say it does and what it actually does, or if it does anything really weird, or if you have any suggestions for how it could be different, please let me know. juniper@tamalpais.net is a good place to send bug reports/comments/requests for new users/whatever.

Logging in:
To do anything except for reading the public posts you'll need to log in. Usernames and passwords are case sensitive. If you're having trouble logging in make sure that Caps-Lock is off and try it a couple times to make sure you typed things correctly. The next thing to do when you have problems is to check and make sure that your browser accepts cookies - in Netscape Navigator this setting is under Edit...Preferences...Advanced. All the "security" for this site is based on cookies. Cookies are little bits of text that this web site send to your browser. They last for the lifetime of your browser. Every time you close your browser or shut down your computer you'll need to log in here again.

If you never got a username and password or need a new password cuz you forgot the old one, email us and we'll fix you up.

Private vs. Public posts:
Only users who have logged in can view the private posts. This is a good place to post things like phone numbers or email addresses or other things that you don't want everyone in the world to have access to. I can't guarantee that they're really private, but there's some security...

Anybody can see the public posts. That's what I meant by public. But only farm web users can create these posts (so that we don't have random people adding links to their porn sites.)

Creating a new post:
When you create a post you'll be asked to give it a title - this is something that should fit on one line. The main body of the message can be pretty much as long as you'd like. You can cut and paste things from your word processor into here. You can even add HTML formatting. But do be careful with the HTML - unclosed tags or HTML comments (things inside <!-- -->) may cause bits of the message to be hidden or other odd behavior.

Once you've entered all the text choose whether you want the post to be public or private and click the Submit button.

Comments and Suggestions:
Send any ideas you have to juniper@tamalpais.net. No idea is too big, too small, or too ridiculous. The only improvements I've got planned is some sort of archiving scheme for when there are too many posts to list nicely on one page...but that probably won't be an issue for quite a while. And maybe someday you'll be able to edit posts that you create.
