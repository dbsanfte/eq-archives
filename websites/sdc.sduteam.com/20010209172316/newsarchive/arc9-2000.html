Listen UP
Posted Thursday, October 26, 2000 by Cozmo

Comments ()

Ok all you high speed internet freaks. We didn't get this stuff for nothing right? Well here is what it can do for you in EQ. Look inside your EQ folder and you should find a file called DataRate.txt. It will be set to 5 which represents a 28.8 connection. Well you can change this setting depending on your connection so the server knows how fast it can dish stuff to you. I set mine to 9 cuase it's suggested not to go above 9 or below 3. This is for a high speed connection.

What this does is allow for faster download of information resulting in faster zoning and a better chance of not getting kicked of in high bandwidth areas (such as large raids). If you change this too high and start having system problems or getting bumped off the game try setting it down a bit. I've been trying this for the past week and have noticed a little bit faster zoning times, but nothing super.
