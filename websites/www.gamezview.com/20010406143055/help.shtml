Help Desk

Welcome to the Help Desk. This page is designed to give you a summary of the features available here at GameZView. It is also designedto provide you with the information required to use these features to the maximum effectiveness.

What is GameZView?

GameZView is the latest addition to the GameZNet family of sites. It has a different focus than our other sites. Where GameZNet is your gateway to the GameZNet family of sites GameZView is your gateway to the internet.

What Features Does GameZView Offer?

GameZView focuses on two major features as well as being a gateway to features elsewhere at GameZNet. These features are news coverage and a search index.

What Features Does the Search Index Offer?

The brand new GameZView search index allows you to easily locate articles for your favorite games, hardware and software. These articles can include reviews, cheats, FAQs, previews, strategy guides, screenshots, developer home pages, fan sites and more.

How Can I use the GameZView Search Index?

Using the GameZView search is easy. In it's simplest form you can simply hit the "Go" button(on the left hand navigation bar) to get a large list of unfiltered pages. That however, isn't all that useful.

The most common way to access our database is to enter a name in to the input entitled "GameZView Search". For example if you were looking for any information regarding the video game Quake you could simply enter "quake" in to the input bar and hit enter or press the "Go" button.

You will next receive a large list of Quake related web sites. This sites are sorted to list the official pages and files first. It will then be followed by other files which are somewhat sorted by our engine. The goal here is to display the most useful information on top so there's less page flipping involved.

One thing you will no doubt notice is that you received a listing of Quake 2 and Quake 3 entries as well. Titles are searched for in a fashion similar to that of search engines. While it is easy to filter for only Quake 2 or Quake 3 titles by entering their "Quake 2" or "Quake 3" in to the search field it is impossible to filter those files out of the original Quake search.

What if you wanted to narrow down your results? We have three drop down filters to ease in this process. These filters fall in to three boxes: Platform, Category and Genre. These filters will be explained in the next section. I wanted to quickly cover how to use these filters here.

To select an option as a filter simply click one of the three drop down boxes and select what you would like to filter to. For example if you were only looking for PC Reviews of Quake 3 you would select PC as your Platform, Review as your category and you would enter Quake 3 in to the text field below clicking the "Go" button.

Platforms, Categories, and Genres

We have already stated that there are three differnet filters for narrowing down your search results. Now we will explain what these mysterious titles are referring to.

Your platform is the type of system that is running this game or piece of hardware. Most computer users will be using PC's. Other computer users might be using a Macintosh or Linux based system. Console users should have no problem in figuring out which console they are using.

The Category Filter

The category filter allows you to filter the types of articles you will be viewing. Each category is explained below.

Article - Articles which do not fall in to any other category. In general they are editorials.
Award - Special awards such as Game of the Year.
Cheat - Cheat codes for particular games. These codes allow you to have unlimited lives, ammunition or other options.
Comparison - Articles which compare one game or piece of hardware to another.
Demo - Downloadable demonstration copies of a game. Usually these are downsized versions of a game which offer one or two playable levels.
Developer - A game developer's home page.
Download - A type of download that does not fall under any other category.
Editing - Software or tutorials which allow you to edit a game. An example would be a level editor or a UnrealScript programming tutorial.
Emulator - Software which allows you to emulate another platform, game or piece of hardware.
Fan Site - Web site dedicated to a particular video game.
FAQ - Frequently Asked Questions pertaining to a particular game or piece of hardware.
Hint - Hints, tips or suggestions for playing a particular game to it's maximum efficiency. These are not cheats and are not complete walkthroughs. They are only minor hints.
Home Page - Official home page of a game or piece of hardware.
Interview - An interview with the creators of a particular game or piece of hardware.
Message Board - Discussion board for a particular game or piece of hardware.
Modification - A program which adds on to an existing product. These are usually created by third parties.
Movie - Downloadable movie which shows off graphics of gameplay.
Patch - An official patch for a game or piece of hardware. Patches are usually to fix bugs but can also improve performance.
Press Release - An official press release.
Preview - This is a glance ahead to a product before it is released.
Review - A review of a particular product after it has been released.
Screenshots - Screenshots showing up the graphics or interface for a certain game.
Spoiler - Spoiler content might include a listing of weapons in an RPG or maps for a game.
Strategy - A full scale strategy guide dedicated to a particular title.
Walkthrough - A front to back solve for a particular game.

The Genre Filter

The genre filter allows you to sort by game or hardware type. Some titles can have more than one genre. Descriptions are listed below.

Action - Action based games such as shooting games.
Adventure - Titles such as Monkey Island or Grim Fandango.
Beat Em Up - Fighting games such as Street Fighter or Tekken.
Controller - Mouse, Joystick, Keyboard, etc.
CPU - Computer CPU chips.
First Person Shooter - Games such as Quake or Unreal.
Massive Multiplayer - Games which take place in huge persistant online worlds.
Monitor - Computer monitors.
Motherboard - Computer motherboards.
Operating System - Windows 98, Windows 2000, Amiga Workbench, etc.
Peripheral - Hard drive cables and other miscellaneous hardware pieces.
Platform Game - Games such as Mario Brother, Sonic the Hedgehog, etc.
Racing - Racing games.
Real Time Strategy - Games such as Total Annihilation or Dune.
Role Playing - Titles such as Baldur's Gate, Ultima or Everquest.
Simulation - Games which simulate a real life or fantasy activity such as flying a plane or commanding a submarine.
Sound Card - Computer sound cards.
Speakers - Speaker reviews or comparisons.
Sports - Games based on a sport such as baseball or football.
Turn Based Strategy - Strategy games such as Civilization where players or computer controlled opponents take turns making their moves.
Video Card - Video Card Reviews.

What Features Does GameZView News Coverage Offer?

With the opening of GameZView we promise to focus our energy on providing the best possible up to date news coverage for today's hardware and gaming.

The most basic way to view news is simply to open up www.gamezview.com in a browser window and news from the past two days will automatically be displayed. We offer a couple of more advanced features as well such as news filters and archived searching.

How Do News Filters Work?

One of these features is the ability to filter your news by category. You can filter your news by clicking on the Customize Your News button above the news box. This will bring up a selection of news topics. Clicking on any topic will result in a collection of news items from recent days being displayed for that particular topic.

For example clicking on the Action button will display any pieces of action news in recent days. Some of these categories are encompassed by other categories. For example the Quake category will only display news for Quake engine titles such as Quake 3: Arena or Half-life. The First Person Shooter category however will list Quake news as well as news from other first person shooters such as Unreal Tournament or Gunman Chronicles. Meanwhile the Action category will not only display all First Person Shooter news but will also include games such as MDK as well.

What Do the Other Three Search Boxes Do?

As you have likely noticed there are four different text input fields in the left hand navigation bar. The first of these navigations bars(GameZView Search) has already been covered in detail. The other three search boxes allow you to get different types of searches. The specifics of these searches will be covered below.

What Does GameZPortal Search Box Encapsulate?

The GameZPortal Search box allows you to access the GameZPortal search engine. The GameZPortal search engine was the original search engine in the GameZNet family. It is a full featured search engine similar to what you might find at Hotbot or Excite. The difference is that the GameZPortal search only allows sites dedicated to gaming or hardware to be indexed.

The search box here is simply the plain vanilla search. It allows for many advanced search types. You can get full details on the search options by clicking here.

You may optionally access the Advanced Search Options by clicking here.

What Does the GameZCheat Search Box Encapsulate?

The GameZCheat Search box allows you to search through GameZCheat. GameZCheat is our popular cheat database. Entering any game name in to the search box will bring up a list of cheats available at GameZCheat.

GameZCheat currently only offers cheats for the latest generation of consoles. We are in the process of expanding it to support PC cheats at this time.

What Does the GameZNewz Search Box Encapsulate?

The GameZNewz Search allows you to filter through all of the news articles here on GameZView. This exact same news is mirrored at GameZNet. This news system was originally part of a seperate site by the name of GameZNewz.com. The decision was made some time ago to merge GameZNewz in to the main GameZNet page. We recently decided to use the same news feeds from GameZNet here at GameZView and have added to the features by adding news categories and search capabilities.

Entering a search field in to this box and hitting enter will bring up a listing of search results from our news archives.
