NOD Engine SDK's NOTEditor Tutorial v.3.1
Introduction
----------------------------------------
	Okay! So there you are with a copy of Vampire installed, and the SDK downloaded and ready to go. You've perhaps never programmed anything harder than your VCR before, but are still interested in creating your own Vampire chronicles. You have the creativity and the vision, but lack the technical talent. SDK is a daunting set of utilities for the uninitiated, so you are not alone. One glance over the various bulletin boards for Vampire reveals that even the programming gurus are having trouble doing even basic things with SDK.
	Don't lose hope! The experts are hard at work deciphering the various bells and whistles of all the SDK utilities, and various tutorials will be coming very soon. To get the ball rolling, I spent the night of the release, and the day after the release, playing with the NOTEditor utility in SDK. Finally, I have achieved my set goal (with the help of many, many gurus on the Nihilistic BB), and I swore that I would write a tutorial on using NOTEditor once I had completed that goal. So, here is the promised tutorial.
	Consider this a brief guide to get you started down the NOTEditor road. The possibilities are truly endless with SDK, but sometimes the first step is the hardest. I hope that this tutorial will help some beginners out there in taking that first step.

What is the NOD Engine SDK?
----------------------------------------
	SDK is a set of utilities released by Nihilistic for the Vampire: the Masquerade - Redemption game. It is intended to put the power of adding to, changing, altering, and sometimes improving the game into the hands of ordinary gamers like yourself. It was not created, billed, or released as a beginner's set of tools. It is essentially the same tools that the designers used to create the game.
	There are essentially three parts to SDK: Embrace (the level editor), NOTEditor (the creature and item editor), and NODView (used to view all the models in the game). This tutorial deals specifically with NOTEditor. For beginners, the NOTEditor is the most intuitive of the three utilities, and is generally regarded as being the best place to start for those wanting to learn but not having previous experience.

NOTEditor
----------------------------------------
	The NOTEditor is the creature and item editor for the SDK set of utilities. With it, it is possible to change almost any quality of an item or creature in Vampire. You can create custom PC's and NPC's (with unique names and skins), give existing PC's and NPC's new (and sometimes strange) abilities, change the aspects of items...almost anything you can think of, within the restrains of the game engine, can potentially be done with NOTEditor. Practical applications range from the simple (making some mortal gang members to confront your Vampire coterie) to the funny (making a werewolf dance like the goth girls in the nightclub).

Important Note on NPC and PC Creation
----------------------------------------
	Unfortunately, multiplayer Vampire does not have any sort of auto-update or file sync feature, so any new or altered files in your Vampire directory HAS to be shared among all your players manually for them to be able to see the changes. So, before running your chronicle, you need to send all altered files to your players, and make sure they place all the files in the proper folders. Below is a list of files altered in this tutorial (and hence, the files that need to be sent to your players when you create NPC's or PC's) and where they each should be saved.

File			Location
Global.not		Vampire/misc/Templates
Multiplayer.not		Vampire/misc/Templates
modernDay.not		Vampire/misc/Templates
darkAges.not		Vampire/misc/Templates
xxx.nai			Vampire/misc/Ai
system.nls		Vampire/strings
mpcharacter.txt		Vampire/misc

	Obviously, only one set of altered files can be used at a time, so unless you are the ONLY Storyteller that your players play with, it may be a good idea for them to create special folders to hold each individual Storytellers set of custom files separately. Then, all they will have to do is place the proper files in the proper folders before a game.

BASIC NPC CREATION TUTORIAL
----------------------------------------
	My original goal when first working with NOTEditor was to create a group of four human gang-bangers that could hold whatever weapon I supplied them with, use that weapon correctly, and would fight the PC's independently of having to be possessed by the Storyteller. This tutorial will take you step-by-step through the creation of basic NPC's and multiplayer PC's, and will hopefully give you a starting point from which you can begin creating your own creatures and items. It was written with the assumption that readers would already have a working knowledge of using the multiplayer Storyteller tools. If you haven't had a chance to play with them yet, I suggest you spend a little time with them and then come back here to learn about NOTEditor's abilities.

1.	First off, we'll start by extracting some needed files. You'll need WinZip for this, so if you don't have it, point your browser to http://www.winzip.com and download the free trial browser.
	Start WinZip and open the "resource.nob" file located in the root Vampire directory. All files will be extracted to the root "Vampire" directory. We will be extracting two sets of file types...".not" and ".nai".
	There are four ".not" files to extract - "darkAges.not", "Global.not", "modernDay.not", and "Multiplayer.not". These four files are where most of the NPC and item information is stored. When you extract them in the Vampire directory, it will automatically create two subdirectories - "misc/Templates". The ".not" files will be inside the "Templates" folder.
	Next, extract the ".nai" files. There are 136 ".nai" files, so I won't list them all here. But, extract them all to the Vampire directory. A new folder will be created inside of the "Templates" folder (called "Ai") with the ".nai" files inside. The ".nai" files contain the information on specific combat parameters for each creature in the game (it's artificial intelligence...hence, AI *grin*).

2.	Go into Windows Explorer and open up the Vampire/misc/Templates folder. Since the files are off of a CD, they are all Read-Only and we need to change that so we can save our changes.
	Select the four ".not" files, open the Properties dialog box, and deselect the "Read Only" box. Click "OK".
	Now, do the same thing for all of the ".nai" files in the Vampire/misc/Ai folder.

3.	Now that we're done with the extractions and changing the Read Only status, open up the NOTEditor.
	Open up the "Global.not" file in the Vampire/misc/Templates folder. You won't actually be doing anything with this file. It just needs to be open for changes to the other ".not" files to take effect.
	Next, open up the "Multiplayer.not" file in the Vampire/misc/Templates folder. This holds most of the information on creatures specific to the Multiplayer game. If you wanted to edit a Modern Day- or Dark Ages-specific creature, you would open it's specific ".not" file and work with those. The creature we will be editing for the purposes of this tutorial is located in the Multiplayer.not.
	Double-click on the "_Cast_STOnly" directory in the left window.
	Double-click on the "_Cast_ST_0" subdirectory.
	Double-click on the "_Cast_ST_0_MD" subdirectory.
	Highlight the "ST_Mugger_MD" file. This is the creature file that we will be editing for our gang members, as it has the look that we want. The NPC's that begin with "ST" are also good because, unlike most of the other NPC's, they will correctly hold and use any weapon that you supply them with. Check the various Vampire-related sites to find complete NPC and creature listings, including stats, abilities, and special functions.

4.	With "ST_Mugger_MD" still highlighted, click on "Template" at the top of the screen, then select "New Sibbling" (their spelling, not mine *grin*). This will create an exact duplicate of the Mugger file inside of the directory. This duplicate is the one we will be making our gang members out of. Think of "sibling" as making a twin brother or sister...
	NOTE - Clicking on "New Child" instead will create a duplicate as well, but into a subdirectory of the "parent" instead of in the same directory. Think of "child" as an offspring of the parent.

5.	Click once on the duplicate "ST_Mugger_MD". You'll see a bunch of numbers and information in the center window, and a directory tree in the right window. This is all the information for that particular file. It looks complicated (and it is), but once you start puttering around in there you'll begin to get a feel for what each thing does. As the worlds biggest programming newbie, trust me on this ;). It will come.
	First off, highlight the "ST_Mugger_MD" in the Name field in the center window. Change it to read "ST_Gang_MD".
	Next, find the second row in the table in the center window. The column labeled "Sort" (the first column) should have "0005" in the second row. When you double click on it, a new dialog window pops up (called Value Editor). This happens when you double click on ANY of the rows, so get used to it because this is where we will be making the specific changes to the Mugger file to make them into gang members. Make sure to eventually check out the windows for all the rows, because there is some good stuff in there. I'll just be specifically mentioning the ones we will be editing for our gang members. Notice that the smaller directory tree in the right window changes according to what center row you have opened up. The second line in this tree describes briefly what information the particular row handles (in this case, "The stringID of this thing description")
	In the new dialog window, highlight "MUGGER" in the String field and change it to "Gang Member". This is what appears when PC's move their pointer over an NPC in the game. Click OK.
	Double-click on the row with "4015" in the Sort column. This designates the starting health of the NPC. Change the "100" to "70" (or whatever you wish. I wanted these gangbangers to be particularly weak). Click OK.
	Double-click on the next row ("4016" in the Sort column). This is the maximum health possible for the NPC. Change the "100" to "70" (or, again, to whatever you wish).
	Double-click on the "4050" row. This is the xp gained for defeating the opponent. Change the "50" to "30". Click OK.
	Next, we will have to ADD a row that isn't in the normal Mugger file. We will add the "AI" necessary for the gang members to be able to fight. Find the "ACTOR_AI" in the directory tree in the right window. Double-click on it to open the dialog window. Next to the "Filename" field, there is a small box with "..." on it. Click once on this box to open a window so we can designate the specific ".nai" file to use for our gangers (remember the ".nai" files from earlier? Here's where they are used...). Go into the Vampire/misc/Ai folder, and locate a file called "genEnemy.nai". Select that file, then click Open, then click OK. The "ACTOR AI" row will be automatically added into the center window. What this did is tell the game that the gang banger NPC will use the combat methods listed in the "genEnemy.nai" file.

6.	Almost done! Now, close NOTEditor by selecting "File" and then selecting "Exit". Do NOT click on "Close", as this will cause an error with the program that will make you have to reboot and start the whole process over. When you select "Exit", the program will ask if you wish to save. Click Yes. It will ask you one more time. Click Yes again. Voila! Your custom gang member is complete!

7.	Now all you have to do is place your gang member! Start Vampire, open your multiplayer game, place your ST head where you want the gang member to be, open your Actor List, and scroll down to find "ST_Gang_MD". That's our gang member!
	To have him attack an opponent, you have to supply him with a weapon. After you place your gang member, place the weapon that you want him to have on the ground, possess the gang member, pick up the weapon, open his inventory, and put the weapon in his hand. All done! Now your gang member is ready to be fodder for your Vampire PC's!

Additional Tips
----------------------------------------
--	By adding the "ACTOR_WEAPON" information (from the directory tree in the right window) to the center rows, you can have the gang members automatically be placed with a weapon in hand (instead of having to give him one with the ST head)! This can be used for many of the NPC's, so play around with it.
--	Many other things can be edited for a particular NPC, including stats, blood, Faith, etc. Feel free to experiment! Different qualities can also be added or removed, including dancing, movement rates, invulnerability...the sky is the limit!
--	The ".nai" files can be further edited by using "Notepad" or a similar text editor. This is most useful for changing particular disciplines that a given creature may have, but you can also change chase and tracking rates, among other things. Many interesting controls in the ".nai" files. Check them out when you are feeling confident!

BASIC MULTIPLAYER PC CREATION TUTORIAL
----------------------------------------
	If you have spent any time in multiplayer games, you have probably seen the vast abundance of "Gothguy" characters running around. It's a great model, so I can't blame people for using it, but you may be a Storyteller that wants to give your players more options in choosing a unique look for their Vampire character. That's where NOTEditor come in to play ;). With it, you can create your own multiplayer PC models from NPC models used in the game. You could even create your own custom skins and have a TRULY unique PC, but that goes beyond the scope of this basic tutorial.
	Many of the steps in creating a custom PC are similar to creating an NPC, but there are some new things we will be doing, so pay close attention to the steps as they are given. You should try using the NPC creation tutorial before moving on to the PC creation, as many of the steps will refer to techniques described in the forst tutorial.
	We will be making a new PC character that uses the Interpol Agent model called Government Agent (he also looks a bit like a scruffy reporter-type, or perhaps a disgruntled NYC cop...quite a few uses).

1.	We will need to extract some necessary files to start with. Using WinZip, open up the "Local_Eng.nob" file in root Vampire folder. Locate the "system.nls" file, and extract it to the Vampire folder. It will automatically be placed into Vampire/Strings.
	Next, still using WinZip, open up the "resource.nob" file in your root Vampire folder. Locate the "mpcharacters.txt" file, and extract it to the Vampire folder. It will automatically be placed into Vampire/misc.

2.	We need to turn off the "Read Only" status on the two files, so open up Windows Explorer, locate the "system.nls" and "mpcharacters.txt", open up the Properties window, and deselect Read Only for both files.

3.	Now we're ready to start editing in NOTEditor.
	Start NOTEditor and open up the "Global.not" and "Multiplayer.not" files (detailed in NPC creation above).
	Double-click on "_Cast_STonly" in the left window directory.
	Click twice on the "_Cast_ST_0" subdirectory.
	Click twice on the "_Cast_ST_0_MD" subdirectory.
	Highlight the "ST_interpolAgent_MD" file.
	Click on "Template" at the top of the screen, then select "Create Sibbling". This creates a duplicate of the Interpol Agent file in the same directory.
	NOTE - The models located in the "_Cast_STonly" directory are the best to use for multiplayer PC's, because they contain all the necessary artwork and animations.

4.	With the DUPLICATE Interpol Agent file highlighted, change the "Name" field in the upper center window from "ST_interpolAgent_MD" to "MP_governmentAgent_MD".
	Then, click and drag the renamed "MP_governmentAgent_MD" file down to the "_player_MP" directory in the left window. This is the directory where all the multiplayer PC's are stored.

5.	Now that the file is in its new location, highlight it.
	Double-click on the "4060" row in center window. Change "ChristophDa" to "MP_Christof.NPC". This controls the base abilities of the PC in multiplayer mode. Keeping the original would result in the model having vampiric disciplines even if he is created as a human. Obviously not something that we want, so we had to change it to a type that didn't have those disciplines.
	Double-click on the "9000" row, and change the selection from "NPCs" to "Players".
	That's everything we need to do in NOTEditor, so click "File" and "Exit". It will ask you twice to save. Answer Yes both times.

6.	Next, open up the "system.nls" file with Notepad (we extracted it in step 1).
	In the section that begins "Multiplayer Character Template Descriptions".
	Add the line "MP_GOVERNMENTAGENT_MD		Government Agent" at the bottom of the list. This ties the proper in-game name to the .not file information. Save it.

7.	Finally, open up the "mpcharacters.txt" file with Notepad.
	At the bottom of the list, add the line: "MP_governmentAgent_MD			MP_GOVERNMENTAGENT_MD". Save the txt file. This adds the proper name to the multiplayer list so it will be selectable when players go to create a new PC, and ties it to the system.nls information, which ties to the multiplayer.not file. Like a puzzle!

8.	Your character is ready to be used! Go into the game, create a new character, and you will see "Government Agent" in the PC selection box. Give him a name, select his starting stats, and he's ready to rock!

Additional Tips
----------------------------------------
--	The "ST_xxx_MD" actors are the best ones to use for PC's, since they contain all the necessary animation and artwork needed (as mentioned above). Use of other actors or creatures is done at your own risk! =)


CUSTOM .NOT CREATION TUTORIAL
----------------------------------------
	Saving new actors and items in the four supplied .not files is fine for some, but other Storytellers prefer starting from scratch and creating a specialized location to save all of the new PC and NPC characters unqiue to his or her Chronicle. That's what this section is for. We will show you how to create a custom .not file in which you can save all of your NOTEitor creations. You can have one huge .not file, or instead you can have individual .not files for each chronicle you run. In addition, we will show you how a simple command line addition to the vampire.exe can enable the program to look in the folder of your choice for files, which enables the Storyteller to create individual folders unique to each Chronicle (look in the Additional Tips section below).
	We'll show you how to create a custom .not file and how to get Vampire to recognize it. If this is your first time using NOTEditor, you should go through the tutorials for creating custom PC's and NPC's first, as many steps reference things done in those tutorials.

1.	Open NOTEditor to begin. Open the Global.not and whatever addition .not files you will be drawing siblings from (Multiplayer, modernDay, or darkAges).

2.	Create a new .not file by clicking "File" at the top of the screen and selecting "New".
	Save your new .not file by clicking "File" and "Save As". Give your .not file a unique name of your choice. Remember this name, as we will be using it later.

3.	To put new actors and items in your new .not file, all you have to do is click and drag from the other .not files. For example, if you had created a "Detective" NPC and saved it in the Multiplayer.not, all you have to do is click and drag the detective's file down to your new custom .not file. It's that easy ;).

4.	Now we have to get Vampire to recognize your new .not file.
	Save everything and close NOTEditor. With Notepad, go into the Vampire/Chronicles folder and open up the .nmf file that corresponds with the chronicle that you will be playing in. For example, if you will be using the new .not file with the New York multiplayer level, open the "MP_New_York_Null.nmf" file. If you created a custom hub (link to the tutorial at the bottom of this page), open THAT .nmf file.
	With the proper .nmf file open, add this line to the bottom of the list:
	"NOT              xxx.not"
	Where "xxx.not" is the filename of your custom .not file. Make sure you put as many spaces (not tabs but actual spacebar spaces) between the NOT and the filename as there are between the other items in the list.

5.	Everything is ready to go! Open Vampire, start a new multiplayer game, and select your chosen chronicle/hub from the game list. When you place your ST head and open the actor or item list, your custom .not file info should show up ready to be placed, along with the info from the normal .not files. Congratulations!
	NOTE - Make sure you open up a NEW unedited chronicle/hub first, and not one that you have saved. Once you open up a new chronicle/hub, it will tie that custom .not to all the saved games that use the same one.

Additional Tips
----------------------------------------
--	For easier chronicle and file management, you can set up custom folder sets for Vampire to draw information from. For example, if you create a chronicle folder called "DarkAngel", you can place all your custom DarkAngel .not, .nai, and hub files into it. Just make sure the path to the files are the same as they are in the Vampire folder (ie. the path to the .nai files would be Vampire/DarkAngel/Ai/xxx.nai, the path to the .not files would be Vampire/DarkAngel/Templates/xxx.not, etc).
	To get the game to read from those files, you need to do two things. First, make sure the DarkAngel (to continue the example from above) folder is in the Vampire game folder. Second, add the command "-user DarkAngel" to the command line of vampire.exe (like adding the -console command). Then, when you start the game, Vampire will look inside the DarkAngel folder to find the custom file sets. This way, you can create custom folders for each chronicle and easily add the proper command line to use them.
