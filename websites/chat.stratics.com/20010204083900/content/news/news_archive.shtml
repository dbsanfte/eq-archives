Entropia Stratics Opens - 3:11 PM EST
 

Stratics is pleased to announce the opening of its newest website, Entropia Stratics. Based on the futuristic Massively Multiplayer title Project Entropia, Entropia Stratics offers the latest in news, rumors, information, and more. Developed by Swedish-based MindArk, Project Entropia is a 3D MMORPG that is just now entering its closed beta, and promises to be one of the most unique titles available.

Centuries in the future, as mankind begins to explore and colonize other planets. they send forth the Odysseus Probes, gigantic spaceships filled with automated robots, designed to prepare new planets for man's arrival. As mankind arrives at Calypso, one such planet, they find an exotic paradise...until without warning the robots begin to attack. As nuclear weapons are put into use, the surviving colonists mutate into bizarre new humanistic lifeforms. Finally, a new generation of colonists arrives to destroy the remaining robots. Only as they prepare to renew efforts to colonize this wild land, the former colonists, now mutants, resist these new intruders. And suddenly a mysterious new threat makes itself known...new breeds of robots that are suspiciously similar to the Odysseus Probes, only modified for one purpose: war.

What makes Project Entropia unique is that it is completely free. No monthly subscription fees, no client charge. Instead, MindArk offers you the opportunity to exchange real dollars for game credits. By doing so, you can purchase new equipment to assist you in the wilds of Calypso. You can also exchange credits back for real cash...making Project Entropia this first MMOG you can make money while playing.

Here are just a few of the many features that Entropia Stratics offers:

  • Hall of New Haven forums

  • Project Entropia Preview

  • FAQ

  • Species index

  • Technology index

  • And more

And for a short time, Entropia Stratics is pleased to offer two Stratics Exclusives: a Project Entropia Desktop Theme and a creature movie. Find them in our downloads section today!

    Mirc version 5.8 has been released! - 12:12 AM EDT
     

    mIRC 5.8 the latest version of the award winning irc client has been released recently. This new version has over 140 Bug fixes and several new features. However most of the new features will be transparent to the average user as they mainly are in the area of scripting.

      Some of the changes and features are as follows:
      • mIRC now uses it's own internal beep.wav sound for event beeps. This was added as option in the general dialog.
      • You can now preview wav/mid files in file dialogs by holding the ALT key and double-clicking a filename.
      • Cancel away on keypress option now works for /me messages.
      • /splay now supports .mp3 files, also added on MP3END event.
      • Improved handling of \\network paths. mIRC can now also be run from a network path and will correctly use that path as root for ini files, folders, etc.
      • mIRC no longer sends a default quit message if you haven't specified one.
