Guidelines:
  1. NO HTML-- Because allowing HTML really screws things up, it is not allowed in this form. If you try to type in data in <>'s, it will just reprint it. I will not be posting images on this site, but I will link them. Please include the full URL to the image, and make sure it is a linkable image (not hosted by one of those unlinkable hosts).
  3. Stupid posts will be removed. Please don't waste my time.
