Please follow these instructions on how to fill in the BoP Application to create an account.
1, Personal Information : All info is not needed and can be stated by the word None or N/A
Only You and Admin may see or change Personal Information
2, All information on your Characters in each game is needed.
If this information is not entered, your application may be deleted. Reason being, that there are already people trying to enter our members database with little to no information. Don't worry though, It takes Admin to approve an application in order to enter the database. And then only admin and that person can edit their own info and no one else's anyway.
3, Each MAIN CHARACTER in a game must have the info needed for a game. If you look at the members list you can see an example. CaScA and Bulaz are the same person but in different games. This is the way the majority of members requested to view members in order to best know who to group with or what game another member is in.
4, If you have any problems understanding these instructions, please ask an existing member in game or email CaScA
CaSca@linkline.com
5, Adding Alts are not implemented at this time.
