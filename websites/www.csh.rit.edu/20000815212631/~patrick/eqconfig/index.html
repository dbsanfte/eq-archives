EQ Config v.95b

Download: EQConfig v.95b(10KB download)

Features

  • Change the color for any message
  • A Color Picker
  • Change the Default view
  • Change the Default Run/Walk setting
  • View a current selected color on the background of the selected view
  • Open and save to alternate filenames
  • VERY small - The executable is 36KB in size


Installation:

Just copy to any directory, EQ Config finds your eqclient.ini
file. It is recommended you back up your eqclient.ini file
just in case a bug has escaped my testing.


Usage:

Upon start, EQ Config finds and read in the settings from
the eqclient.ini file. Change the values as desired and
Export the new values by clicking on the File/Export menu.
