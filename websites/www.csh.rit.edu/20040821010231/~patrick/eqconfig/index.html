EQ Config v1.0

Download: EQConfig v1.0(11KB download)

Features

  • Change the color for any message
  • A Color Picker
  • Change the Default view
  • Change the Default Run/Walk setting
  • Change Log option
  • View a current selected color on the background of the selected view
  • Open and save to alternate filenames
  • VERY small - The executable is 44KB in size


Installation:

Just copy to any directory, EQ Config finds your eqclient.ini
file. It is recommended you back up your eqclient.ini file
just in case a bug has escaped my testing.


Usage:

Upon start, EQ Config finds and read in the settings from
the eqclient.ini file or uses the default options if this file
cannot be read. You can open another INI file by clicking on
File/Open. Change the values as desired and export the
new values to eqclient.ini by clicking on the File/Export
menu. You can also save the settings to another filename
by clicking on File/Save As
