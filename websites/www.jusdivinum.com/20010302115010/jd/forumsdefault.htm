Message Forums

We are using the ezboard service for our message board service providers. They have a lot of fun things that we can do and it also gives you all a lot more control over your posts. The new message boards require that you create an account if you do not have one with them yet. If you already do and you don’t want to use your current account for the Jus Divinum boards then you can just create another account. Anyone can have as many accounts as you want; all you have to do is follow the link below to set up your account.

The public boards have no password (of course) and the private members only boards are currently the same password as before. The officer’s board has a new password so drop me a line.

New things you’ll be able to do with the boards:
  • EDIT your own posts (Woohoo!)
  • Preview your post before you post it
  • Listen to the web radio while you read
  • Customize a personal photo that will display with your posts
  • Customize the boards to react to the way you like to view them
  • Run your own polls
  • Easily add images, links and other basic HTML through EzCodes
  • Plenty of online help that will guide you on how to do things
  • See how many replies have been made to your post and who last replied
  • See how many members have viewed your post
  • Email topics to friends
  • For advanced users customize your own HTML in posts
  • Search for information
  • Leave voice messages for all to read
  • And much, much more ...........

The personal images are 60x60 pixels and for those that want an image but don’t have the tools. Then email me the image and I’ll take a headshot (crop) and email the image back to you. This way all you have to do is post the image. For those of you that don’t have the web space to do it, there is an option online that stores the photo for you. You’ll see what I mean when you do you preferences, it is called "Facelink".

If you already have an account, but want to represent your "character" on the JD message boards, then make sure that your current account is set up for your character. If you don’t want to use your current account, then create another account for your character.

To create a new ezboard account, follow this link: Create Account

If you have an ezboard account that you want to use with the JD message boards then go to the new message boards by following this link: Jus Divinum Forums

If anyone is having problems then feel free to email me by clicking here and I will help you the best that I can.
