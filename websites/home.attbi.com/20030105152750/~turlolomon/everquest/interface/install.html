Install Instructions

I have spent a lot of time on the phone or on-line talking with friends giving step by step instructions on how to install my personal UI Mods. I have decided to expand upon this and type them out to help others out there that do not know how to contact me.

There are three different tasks that every person should already know how to do. How to download a file, how to UnZip a file, and how to make a directory. For those that feel this is silly, just understand that I have spent hours on the phone discussing these particuliar functions. Once you know how to do these three basic functions, continue with these instructions. Oh, and in case you can't figure it out, "folder" means the same thing as "directory".

My UI Mods are written for 800x600 resolution. If you use a different resolution, I recommend installing pieces of the files, but not the INI files discussed below.

First, find your EverQuest directory. It is usually located "C:/Program Files/EverQuest". Within that directory, you will find a folder called "uifiles". The full path to this directory is:

C:/Program Files/EverQuest/uifiles/

Within this folder you will see "default". This is the standard User Interface that EverQuest uses. Never change anything in that folder. That would be bad. You will need to create a new directory. For this example, let's call it "bard".

C:/Program Files/EverQuest/uifiles/bard/

This is the directory you will place the files that form the custom UI Mod. For a bard, you will need to download three files. Melee (required for all), Caster (since bards use mana), and Bard (class specific). This is also the same order you will need to install the files, so to speak.

First, extract the files from "melee.zip" to your "bard" folder. Second, extract the files from "caster.zip" to your "bard" folder. If a prompt comes up asking if you wish to overwrite files, say yes. This is the main reason the files are installed in the order that I am mentioning.

Finally, the finishing touches. Extract the files from "bard.zip" to your "bard" folder. Overwrite files as stated above. This completes all the files you need. Now to configure them for your character.

In the "bard" folder is an INI file entitled "UI_Custom_71.INI". This is the character file for the settings on the UI to let everything be in the correct place. Two things need to be done to this file. First, a rename. Change "custom" to your character name and "71" to your server number. Example:

UI_Sebastiana_73

Second, open the file. Your computer should do this automatically by just double clicking on it. You will need to change one line to dictate where your directory is. In our example, we are changing "caster" to "bard". Example here:

[Main]
UISkin=bard

Finally, move the newly renamed INI file into your main EverQuest directory. Overwrite your existing file, and you are ready to Rock N' Roll. Post on the board if you have any questions regarding this procedure. Good luck and happy hunting!
