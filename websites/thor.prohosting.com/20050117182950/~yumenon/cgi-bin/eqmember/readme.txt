【概要】

このスクリプトは、フリーウェアです。

Ever Questとは、ネットワーク３ＤＲＰＧです。

自分のホームページにて使用しておりましたが、整理して公開いたします。
用途が限られているので、はたして使ってくれる人がいるかどうかが
興味あります(^^;

申し訳ございませんが、設置＆障害に関するサポートは受け付けておりま
せん。ご自身で解決していただくよう、お願いいたします。
（障害、ご意見はご報告いただけると幸いですが、修正の義務を負いません）

Perlをご存知ない方でも"option.dat"を変更するだけで、
基本的な部分をカスタマイズできるようになっています。

　・タイトル
　・マスター／共通パスワードの設定 ( 半角12文字まで )
　・個人用パスワード初期値の設定 ( 半角12文字まで )
　・ギルドワークの表示 ( GM, Offcier等の表示欄の有無 on / off )
　・ＧＭの指定 ( ギルドワークの表示ONの場合に有効 )
　・ＯＦＦＩＣＥＲの指定 ( ギルドワークの表示ONの場合に有効 複数指定可 )
　・トレードスキル登録の有無 ( on / off )
　・トレードスキル登録有効時の、初期画面状態 ( on / off )
　・ギルド名欄の表示 ( 登録者毎のギルドの表示欄 on / off )
　・ギルド選択肢 
　　( 所属無しの選択は、プログラム側でリストに空白を設けています）
　・背景色
　・デフォルト文字色
　・ギルドワーク文字列色
　・upper50のレベル文字列色
　・項目名背景色
　・1st char 背景色
　・2nd char 背景色
　・ベストトレードスキルの色
　・1st char 数の統計表示 ( on / off )
　・1st char の平均レベル ( on / off )
　・コメントの文字数制限 ( 半角にて計算 )
　・戻りページ指定

【インストール】
１）option.datの内容を、お好みで変更してください。

　　各項目にはコメントがついていますので、ご参考ください。
　　初期状態では、以下のような設定になっています。
　　・ギルド用
　　・トレードスキルの登録はあり。初期状態では非表示。
　　設定をかえることにより、サーバ単位のメンバー表も作成可能です。

２）全てのファイルを、サーバ上の同じディレクトリにアップロードします。
　　ファイルは全て「テキスト」形式にてアップロードしてください。
　　アップロード後、全て小文字になっていることをご確認ください。

３）拡張子「cgi」と「pl」のファイルの属性を実行可能属性
　（755 or 705）に設定してください。

４）member.datを書き込み可能属性（666 or 606）に設定し
　　てください。

５）ブラウザにてmember.cgiを呼び出せば、使用できます。

注意）プロバイダによっては、cgiファイルとその他のファイルを別ディレクトリ
　　　に配置しなければならない場合があります。
　　　その場合は、cgiファイル内上部に記述されているパス名を変更してください。

【メンテナンス】

・書き込みしたデータはmember.datに蓄積されます。
　データ消失をさけるため、追記書き込みしか行っておりませんので、
　長期間、多人数での使用をする場合はメンテナンスが必要です。
　メンテナンス機能（ログの整理）機能は、manager.htmlから「データの整理を行う」
　を選択してください。
　過去のデータが削除され、最新のデータのみ残してmember.datを書き換えます。
　書き換え処理を行いますので、データ消失の危険性があります。
　万一のため、ＦＴＰなどでmember.datを退避してから行ってください。
