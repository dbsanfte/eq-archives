TimerMod is an EverQuest user interface modification that integrates custom timers into your EQ display. The timers allow you to keep track of various in-game events.


See feature list and screenshots

Example uses include:

  • Mesmerize and pacify spells
  • Slows, snares, other debuffs
  • Damage over time spells
  • Buffs for other players
  • Activated ability re-use time
  • Discipline duration/availability
  • Spawn cycles
  • Adventure deadlines
  • Tribute intervals
  • Elapsed play time

    • Highly Customizable
    TimerMod has many customization options available, allowing you to create your own unique timer configuration for your specific needs and preferences. Your files are dynamically generated upon download based on options you select.

    Easy Setup
    The timers are easy to customize and install. Simply follow the step-by-step configuration wizard to create and download your custom file package, then unzip the files into your UI mod folder. No file editing is required! You can install TimerMod while staying logged into the game.

    Helpful Tools
    When customizing your timers, look up spell/ability information easily using the provided search box. Adjust durations for AA and focus effect modifiers, or set the duration by section, using the duration calculator. The timer preview allows you to see what your configuration would look like before downloading.

    Quick Reconfiguration
    If you get new spells/abilities, or just want to change your timers for any reason, you can reconfigure your existing timers quickly without having to re-enter the information. Just use the link provided in your original download to launch the configuration wizard with all your current selections already filled in. Make the changes you want, then simply replace your existing files with the new download.

    UI Compatibility
    TimerMod occupies the unused window of your choice, and can be used with other interface modifications. Choose from 26 different windows in the UI. The dynamic file generator has been, and will continue to be, updated regularly to ensure compatibility with every EverQuest patch.
