Eqq Timer

This is a program created by Juniper to time just about anything you want.
Be sure to read the instructions before attempting to use this.

Note: Eqq Timer does not in any way intercept, interfere with, nor modify the data stream from the EQ client to the EQ servers. Eqq Timer is a totally standalone program designed to run from a second computer that is not running EQ. Eqq Timer also does not contain any EQ copyrighted material (sounds, graphics, text, whatnot). Any questions can be directed to: eqqtimer@maniacallegions.com

EQClient Editor

Problems getting the text colors to your liking?  This little gem will set them for you.
This will save you time and headaches trying to get the color codes right.  This was not developed by us but is a great tool to customize the User Interface.
