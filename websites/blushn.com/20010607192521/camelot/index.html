Trade Skills....
Posted Thursday, May 24, 2001 by Bree
MahrinSkel gave some insight as to what will be involved and how trade skills will work in the game. This is an excerpt from the full article :


"Now, as far as the general structure, there will actually be a large number of skill, which can basicly be divided into Materials crafts and Process crafts. A Materials craft skill will be a measure of how much you know about working with that kind of material, a Process craft skill will be a measure of how much you know about a particular kind of product."

Posted This Morning....
Posted Monday, April 9, 2001 by Bree
Camelot Beta 3 Application Closed

As of this morning, we've closed down the Dark Age of Camelot Beta 3 application page. Thank you to everyone who applied -- the response has been overwhelming, with over 33,000 applications.

We'll be sifting through the applications over the next few days, and will be opening up the beta about 50 players at a time starting later this week. You'll be notified via email if you have been selected.

Beta 3 Update......
Posted Wednesday, March 28, 2001 by Bree
Posted on the Official DAoC site.............

Online applications for Dark Age of Camelot's Beta 3 will start to be taken on Monday April 2 at 12:00 noon. The application process will work much like that of Beta 2 -- an online application will be located under the beta link on this web page. We'll leave the application up for a week or more in order to gather many names, from which we'll select the lucky applicants, who will be notified before the start of Beta 3.

More information about Beta 3's start date will be released soon. Please check back for updates.
