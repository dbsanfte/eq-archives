EQBoard bugs fixed
Sunday, February 4, 2001 @ 9:41PM PST
Posted by: Golggen   -   [top]
     Two bugs on the EQGuardians.com EQBoards have been fixed.

Dec. 31, 1969 Bug
One such bug has been called to my attention in the Bugs forum. When displaying a user's join date, and last post date, they would both return Dec. 31, 1969. Kinda funny considering this wasnt even arround in 1969 (of course). Also that I never once entered in 1969 as any part of the script. If anyone is interested in why for some reason... in the script the date was called up via the following line:
$postdate = &longdate("$postdate + ($timedifferencevalue*3600) + ($timezone*3600)");
when it should have just been:
$postdate = &longdate("$postdate");

E-Mail Problem
I wont go so far to call this a bug really, just that I made a typo in the path to the Sendmail program on the server. Registrants may now use more features which require the Sendmail program (for example, recieving e-mails upon replies to your post).
Also, as a security measure, new registrants will have a random password emailed to them which they can later change simply by editing their profile.

Since these bugs have been fixed, I have gotten rid of the post on that bug. (for those of you wondering where it went)

--Have fun!
