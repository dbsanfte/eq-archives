JRun Servlet Engine

JRun is a server side extension that allows your web server to execute Java server side components, or Servlets, for the processing and display of information. In other words, rather than using Perl, C, C++, or other backend CGI languages, you can write your server extensions in Java using the Java Servlet API. Java greatly simplifies coding and has a tremendous number of useful resources for the programmer. JRun has been optimized for speed and is tightly integrated with the server's internal API. ensuring fast throughput and response.
