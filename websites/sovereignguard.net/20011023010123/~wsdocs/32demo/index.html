Server Self-Test & Demonstration

22-January-2001
This document exercises (and demonstrates) many of the capabilities of the WebSite Professional 3 server. Please take the time to work through each feature. Don't worry if the more esoteric features don't seem to make sense; you'll know the reasons for them soon after you start using the server in a development or production environment.

For additional information on these features, check out the WebSite Pro Resources (available from the WebSite Professional program group on the Start menu) as well as WebSite Central. If you are having difficulties, please consult the Help and Reference section of the WebSite Pro Resources or the WebSite Support Center.

Self-Test Checklist

Use this checklist to verify your setup:

  • You are using a browser that supports forms, image maps, tables, and basic authentication (most do)
  • You have enabled automatic fetching of inline images
  • Your browser is configured to accept and view GIF and basic sound
  • You have a GIF viewer and sound player installed and tested with your browser
  • The WebSite Pro server is running
  • You are reading this document from the server (not as a local file)
  • For the Windows CGI examples, you have at least the Visual Basic 6.0 runtime modules installed.
  • You have added yourself as a user in the Web Server realm, and added yourself to the Administrators group.

List of Features for Demo/Test

Your new server has the capabilities you need to produce powerful yet easy-to-use presentations and services. It supports the following main features:
  • Information Retrieval
    • Basic document retrieval (hypertext, plain text, images, audio)
    • Directory listing and file retrieval (fancy alternative to FTP site)
    • Clickable image maps (actions based on clicking hotspots in an image)
    • Server-side includes (merge documents, use page counters, and more)
    • Automatic URL-fixup (esoteric, but vital)
  • Security Features
    • Cryptographic security
    • Access control
    • Username/Password per-directory access control
    • IP address and host name filtering
  • WSAPI, ISAPI, and Perl 5 via API
    • Notes
    • WSAPI - forms processing and file uploading
    • Perl Version 5 - API Style
  • WebSite's Two CGI Interfaces
    • Using Visual Basic, Delphi, or other Windows programs (Windows CGI)
    • Using perl, Python, and shell (console-based) applications (standard CGI, Unix-compatible)
  • Using CGI Programs (VB, C, perl)
    • Sample order-entry application (using Visual Basic 6.0)
    • Processing fill-in forms
    • Server-push animation (requires server-push capable browser)
    • Forms-based file uploading
  • Miscellaneous:
    • Viewing the server's statistics
    • Server administration with your browser
