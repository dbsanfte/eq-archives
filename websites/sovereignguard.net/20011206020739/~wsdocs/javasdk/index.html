The WebSite Pro Java Servlet SDK 1.2 provides a framework for developing Java servlets -- Java server-side applications that run in the WebSite Pro program space. Version 1.2 updates integrated support for the JavaSoft Java Servlet API and fixes a couple of minor bugs in WebSite's servlet API. JavaSoft Java Servlet support is provided by JRun(tm) technology licensed from Live Software, Inc., of San Diego, CA. Live Software has a comprehensive line of ready-to-use servlets that will run with WebSite Professional. Both types of servlets share WebSite Professional's internal Java interpreter, which means you're assured of fully overlapped, multi-threaded, very fast execution. The SDK includes:

  • The foundation classes for JavaSoft Java Servlet programming, including the servlet API classes and the JRun support classes that integrate with WebSite Pro.

  • The foundation classes for WebSite Pro Java Servlet programming. These classes support WebSite Pro's WSAPI features and other powerful extensions such as automatic form decoding, session tracking, cookie encapsulation, and browser capabilities.

  • Global exception handlers to assure that unhandled Java program errors are caught and reported to the browser.

  • A pair of Windows dynamic link libraries (DLLs) that integrate the Java interpreter into the WebSite Pro process space and provide the interfaces between The WebSite Pro and JRun/JavaSoft servlet APIs and WSAPI.

  • The Java Runtime Environment to enable you to run Java servlets without installing the Java Development Kit. This is installed only if you have no JDK installed on your system.

  • Complete API-style documentation for the WebSite servlet API foundation classes. The JavaSoft Java Servlet API documentation is also included as part of the JRun online information.
