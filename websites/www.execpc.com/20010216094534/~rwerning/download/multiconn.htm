Creating a 3 Tier application, using TDComConnection.

We’ll need a 3 tier connection to start the demo, so that’s where we’ll start the demo. For clarity sake I will be naming things as we go along so we can refer to the components by name.

This demo has been written using Delphi 5, Enterprise. One of the features of Delphi5 is the Project group, which allows you to have multiple projects as part of one project group so that all can be opened and worked with at the same time. Some modifications to the steps will be needed for Delphi 4.

For the sake of this demo, the client and server will both be executed from the same machine. This demo has been put together on WinNT, there are some issues with using Dcom connection on Win9x, please see Dan Miser’s articles at http://www.distribucon.com/ for more information on using Dcom with Win9x.

During the demo we will be using the TSharedConnection component, this can be found in the Midas Essential pack at http://www.openave.net . Another handy part of the MidasEssential pack is the CDSGrid (Client Dataset Grid) which was written by John Kaster. This Grid connects to a TClientDataset, and allows for sorting by one or more columns on the fly, simply by clicking on the column title. A nice addon component in my opinion.

Building the Server

Create a new application ( File | New Application), this will be our server. Save all, naming the form (frmServer) and the project (SharedDemoServer). Now we need to add a RemoteDatamodule (File | New | MultiTier – RemoteDatamodule). CoClassName = SharedDemoMain, Instancing = Multi Instance, Threading = Appartment.

  • Add a TDatabase to the RDM (RemoteDatamodule), set the Aliasname = DBDemos, DatabaseName = dbSharedDemo.
  • Add a TSession to the RDM, set the AutoSession property to True. Change the SessionName on the TDatabase to be this session, not Default. The sesssion name will be something like "Session1_1".
  • Add a Tquery to the RDM, change properties so name = qOrders, Database Name = dbSharedDemo, Sql Text = select * from orders.
  • Add a TdatasetProvider to the RDM, change properties so name = dspOrders, Dataset = qOrders.

Check to be sure that the Database Active = False, and Session Active = False. Save all.

Compile the server and run it – this will register the server with your machine.

Building the Client

If you haven’t worked with a project group before, you’ll get your first demo in its usefulness now. In the Project Manager ( Project | Project Manager ) right click on the ProjectGroup1 and add a new project – (New – Application). Name the newly created form frmClient. Save all, naming the new project SharedDemoClient. Looking at the Project Manager, which ever project is bolded is the current active project. Throughout the rest of this demo, you’ll need to be sure that you’re working on the correct project. Be sure that the SharedDemoClient project is bolded in the project manager.

  • Add a new Datamodule (File | New – Datamodule). On the objectInspector set the Datamodule name = dmMain.
  • Add a TdcomConnection to dmMain. Since client and server will be on the same physical machine, leave the computer name blank. Set the ServerName = SharedDemoServ.SharedDemoMain (if this isn’t available in the dropdown list, try to compile and run the server again, the server object likely isn’t registered yet).
  • Add a TclientDataset to dmMain, in the object inspector set the properties Name = cdsOrders, RemoteServer = DComConnection1, Provider Name = dspOrders.
  • Add a Datasource to dmMain. Name = dsOrders, Dataset = cdsOrders

My personal preference is to remove all Datamodules and forms form the projects autocreate list and create them myself in the forms OnCreate event. If you choose to leave the Datamodules in the Autocreate, be sure you move the form to the bottom of the list, creating it after the Datamodule or you will get an AccessViolation when the form tries to open the dataset.

On frmClient add a TDbGrid ( or TclientDatasetGrid if you’ve installed it from the MidasEssential Pack). Add dmMain to frmClient’s uses clause, and connect the grid to dsOrders. In the frmClient’s OnFormCreate event, open cdsOrders ( dmMain.cdsOrders.Open). Be sure that the TDatabase Active = False, then compile the client and run it. The Client should run, opening up and retrieving data from the server.

Adding a Second RemoteDatamodule, using TSharedConnection.

Normally, if you wanted to use another pair of Datamodule/RemoteDatamodule’s you’d have to assign an additional TCnnection (ie. TDComConnection) to handle the communication. However, the MidasEssential pack provides a TsharedConnection component which allows us to share an existing connection (hence the name).

To show how to use the TShareConnection, we’re going to add another DataModule to the client project and RemoteDataModule to the server project.

Modifying the Server

D5 users - Remember to set the SharedDemoServer as the active project in the Project group.

  1. Add a new RemoteDataModule ( File | New | Mulitier - RemoteDataModule ), CoClassName = SharedDemoChild1, Instancing = Internal, Threading = Appartment.
  2. Add TQuery (name=qCustomer) and TDatasetProvider (name=dspCustomer) to the RemoteDatamodule. Set SQL for the new query ( Select * from customer). Set the Session = Session1_x, and the DatabaseName to dbSharedDemo.
  3. In the Interface section of SharedDemoChild1 RDM, add a variable declaration of type TComponentFactory for the Child Type.
    4. var
      fChild1RDMFactory: TComponentFactory;
  4. Modify the existing Initialization section of the server form. In the Initialization section add assignment of the variable when creating RDM. Be sure to the Instancing is set to ciInternal, not ciMultiInstance.
    5. initialization
      fChild1RDMFactory := TComponentFactory.Create(ComServer, TSharedDemoChild1, Class_SharedDemoChild1, ciInternal, tmApartment);
  5. Open projects Type Library ( View | Type Library )
  • Add a new Interface of IBaseRDM to SharedDemoServer. (Parent Interface = IappServer)
  • Add Read/Write property to IBaseRDM for SessionName (type = WideString)
  • Add Read/Write property to IBaseRDM for MainDM (type = ISharedDemoMain)
  • Change the Parent Interface type of the ISharedDemoChild1 to IBaseRDM
  • Add a new Readonly property to IsharedDemoMain named Child1DM, (type = ISharedDemoChild1)
  • In the SharedDemoMain function "Get_Child1DM", add the following code:
    • function TSharedDemoMain.Get_Child1DM: ISharedDemoChild1;
    begin
       Result := fChild1RDMFactory.CreateComObject(nil) as ISharedDemoChild1;
       Result.MainDM := Self;
       Result.SessionName := Session1.SessionName;
    end ;
  • Add a variable to RDM SharedDemoChild1 Private declaration:
    • private
       { Private declarations }
       FMainDM: ISharedDemoMain;
  • Add methods to RDM SharedDemoChild1 Public declaration
    • public
    { Public declarations }
       function Get_MainDM: ISharedDemoMain; safecall;
       procedure Set_MainDM(const Value: ISharedDemoMain); safecall;
       function Get_SessionName: WideString; safecall;
       procedure Set_SessionName(const Value: WideString); safecall; end;
  • Add the Read/Write procedures for MainDM and SessionName.to RDM SharedDemoChild1
    • function TSharedDemoChild1.Get_MainDM: ISharedDemoMain;
    begin
       Result := FMainDM;
    end ;

    procedure TSharedDemoChild1.Set_MainDM(const Value: ISharedDemoMain);
    begin
       FMainDM := value;
    end ;

    function TSharedDemoChild1.Get_SessionName: WideString;
    var
       i: integer;
    begin
       Result := '';
       if FMainDM <> nil then
         with FMainDM do
          for i:=0 to ComponentCount - 1 do
         if Components[i] is TSession then
         begin
         Result := TSession( Components[i] ).SessionName;
         break;
         end;
    end ;

    procedure TSharedDemoChild1.Set_SessionName(const Value: WideString);
    var
       i: integer;
    begin
       for i:=0 to ComponentCount-1 do
       if Components[i] is TDBDataset then
       TDBDataset(Components[i]).SessionName := Value;
    end ;
  • Add unit SharedDemoChild1 to the ShareServMain unit.
  • Compile the Server, and run it to Register it.

Modifying the Client

We now will add an additional Datamodule to the Client, add a SharedConnection to use the existing DcomConnection, and connect it to the client form.

  1. Add new Datamodule. ( File | New | New | DataModule ), Name = dmChild1
  2. Add dmMain to dmChild1 uses statement ( File | Use Unit )
  3. Add a TSharedConnection to your new Child Datamodule, Name = scChidl1, Parent Connection = DCOMConnection1, Object Name = Child1DM.
  4. Add a TClientDataset to dmChildl, Name = cdsCustomer, Remote Server = scChild1, Provider Name = dsCustomer
  5. Add a Tdatasource to dmChild1, Name = dsCustomer, Dataset = cdsCustomer
  6. Add dmChild1 to the uses clause of the frmClient.

Be sure that the scChild1 (SharedConnection on dmChild1) has connected property set to false, and DComConnection on dmMain has Connected set to false. These will often get set to true, as you select providers and remote servers, which causes the server to launch. Compiling and running when they’re active are often a cause of problems when developing C/S applications.

If you choose to leave the Datamodules in the projects Autocreate list, be sure you move the form to the bottom of the list, creating it last.

On frmClient add a TDbGrid ( or TclientDatasetGrid if you’ve installed it from the MidasEssential Pack). Add dmChild1 to frmClient’s uses clause, and connect the new grid to dsCustomers. In the frmClient’s OnFormCreate event, open cdsCustomer ( dmChild1.cdsCustomer.Open). Be sure that the TDatabase Active = False, then compile the client and run it. The Client should run, opening up and retrieving data from the server.

Adding Additional RDM’s to the demo

Adding additional RemoteDatamodules to the demo is relatively simple. You add another RemoteDatamodule ( ISharedDemoChild2 ) to the server, the same as you did the first one (SharedDemoChild1). You will need to modify the Server's Type Library, adding in a Child2DM to ISharedDemoMain and setting the type to ISharedDemoChild2. You need to set the Parent Interface of ISharedDemoChild2 to IBaseRDM, the same as you did for Child1.
