APPLICATION SCREENSHOTS

We have added some screeshots of the BattleVoice user interface so you can get an idea of how it works and what it can do.

This first screenshot shows the main screen and the general phrase list. The dialog box open is the edit phrase box where you can edit the selected phrase and change how it sounds and what the output is. As you can see, you can change the output to be completely different than what you say.

In the next screen shot, you can see that there are MOB lists for every zone in the game that contain the names of the MOBs for that zone. You load the zone when you enter it in the game by saying "load <zone>" and this allows you to have phrases that contain MOB names. An expample is the phrase "root the <MOBs>". If this phrase is in your phrase list, you can then say "root the skeleton" when you are in Unrest and have loaded Unrest.

The next screeshot shows the testing mode. By pressing the listen "ear" button in the toolbar, BattleVoice will start listening and you can test your phrases and recognition. You can see in the display window that we have tested normal say mode, group say mode and tell mode using the friends word list. Notice how the phrases that are displayed use word lists like spells, Mobs and and health/mana. For expamle, when you see the phrase "all on the skeleton" the actual phrase in the phrase list was "all on the <MOBs>" So that phrase would work for any mob in Unrest, since the Unrest mobs were loaded at the beginning.
