The SBLive does like to take a few IRQ's but the latest drivers at least
let you tell it to share the printer irq with the dos emulation. This is
a really handy thing if you are short on IRQ's as I am, because you
can't remove the old sb emulation, other than by marking it unused in
this configuration with the system control panel. My machine has 2
network cards in it as well as the usual run of the mill cards and was
basically out of IRQ's.

On the down side, EQ's sound balance with the 3d audio for the SBLive is
a complete disaster. If the SBLive didn't sound so good in every other
game I'd be tempted to put my old Aureal card back in. Hopefully the new
DX7a version of the client will let them straighten this out but the
version on the test server right now still sounds pretty bad.
