I've updated my EQ log split program to work better with the new
eqlog_xx_charname.txt file name format.

You can now select multiple files to split up, and I added a new filter to
the file selection box to only show files matching eqlog*.txt.

The program is not as useful as it was before, now that EQ saves seperate
logs for each character. But this program will split the logs by play
session, making it easier to run a parser against just the part that you
want to analyze, so there is still a need for it.
