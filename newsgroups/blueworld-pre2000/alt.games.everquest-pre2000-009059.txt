The /who searches are a bit buggy.

I don't mind that the searches will preferentially match races or 
classes over names.  Names that are a prefix for a race or class should 
be forbidden, such as the elf named "High" on E'Ci.  I am not sure 
whether people who named themselves "Shadow****" were thinking clearly 
since their friends will have to type out the whole name to look for them.

You will match guild names before character names always, even if you are 
doing a local /who which won't find guild names.  For example, "/who Syl"
will not find my friend Sylverlokk even if he is in the same zone because 
there is a guild named "Sylvan Something-or-Other" that prevents the 
search from finding him.

You will match only the first guild name found when you search globally 
for a guild.  So if you have a guild called "Fires of Gloating", a search
of "/who all Fires" will find members of that guild and would not find
"Fires of Heaven".  (Actually, I am not sure whether the first one found 
by the search is the first one alphabetically or the first one created.)

There is some ability for the GMs to mess with the /who searches.  At one
point "/who all shitonastick" had a very funny return on E'Ci.

I think there should be a separate search by guild names since I am never
ever looking for the set of all people who might be named "Foo" and the
set of people belonging in a guild that starts with "Foo" in the same search.

It would also be nice if there were also a separate search for counting 
that ignored anons.
