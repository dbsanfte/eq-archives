I have a Soundblaster PCI512.  It uses the same environmental audio chip as
the SB Live, and I had many of the same problems with it when Verant changed
the sound stuff.

Even with the latest drivers, things were never quite right, and never
worked as well as they did before That Infernal Patch.

But then I had an idea.  It's a four-speaker card, and I only had two
speakers.  What if the game was ignoring this, and trying to use four
speakers?  So I got a second set of speakers and wired them up.

No help.  In fact, there was no sound at all coming from them.

So I started thinking a bit more, and wondered if I needed to activate them
somehow.  I dug up the installation CD, and installed their Audio HQ
program.  Yep, you have to tell it that you have four speakers before it
will use them.  But it still didn't help.  Sounds that should be loud were
soft or non-existent, and vice versa.

But then I saw another tab for maximum simultaneous wave voices.  It was set
to the default of 4.  I cranked it up to the max of 32.

This made a BIG difference.  The music sounds MUCH better.  I can hear
instruments that I didn't even know were there.  And even better, the sound
effects in the game are much closer to what they were pre-patch.  There are
still a few things that aren't quite right, mainly sound effects while
fighting, but it's much better than it was.

So if you're like me, and don't bother installing the fluff on the
application CD (and most of it IS fluff), try this and see what happens.

If you've already installed Audio HQ, crank up the wave voice count and see
if that makes a difference.
