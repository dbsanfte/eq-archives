I agree (though not on all the cross-posting). I'm a amateur programmer
myself, and know a few that do it for a living. All of them, as well as
myself, keep little applets (what the term was first applied to) that do
very specific things, and try to re-use them as much as possible. Kind of
like using link-n-logs to build a house, same logs different house.
Programming has always been time consuming, but with the length of code
involved today it only makes sense to recycle as much code as you can.
This happens with games too, look at how many games get written for another
company's "game engine" any of the Quake engines are a good example.
