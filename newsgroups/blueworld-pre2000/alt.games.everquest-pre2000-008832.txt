 I don't think there is a way to "enforce" roleplaying in an acceptable 
way, server wide. What constitutes roleplaying is way to subjective.

 The best I can think of is to merely advertise and label one server as 
a roleplaying server, and open it at a time when several other new 
servers (or transfer servers) become available. 

 Have the server have a log in message/disclaimer that it's intended for 
roleplaying, and non-roleplayers might find it - hmm - difficult. 
Perhaps include a link to a roleplaying guide. 

 This would allow those interested to have a clearly identified server 
to (start on/move to). It would also allow those that weren't interested 
to still have somewhere else to (start on/move to). 

 In the best case, the density of roleplayers on the server is high 
enough that they are pleased by having lots of folks to roleplay with. 
Those that actively conflict with roleplaying will hopefully be driven 
out by societal peer pressure ("Twink me plz d00d". "I cannot trade with 
thee if thou cannot state your needs clearly, sirrah".)

 Of course, roleplaying on the server would hopefully be enhanced by the 
presence of lots of folks willing to form roleplaying conducive guilds, 
run player driven events, and so on. Perhaps Verant might encourage 
roleplaying friendly GMs to be/train on this server, and use it as a 
testing ground for GM events. 

 In the worst case, it ends up a server like any other, and were no 
worse off than we are currently.
