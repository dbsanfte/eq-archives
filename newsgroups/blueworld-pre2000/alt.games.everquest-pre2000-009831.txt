> >Question then... If posting it on web site among other rules, mentioning
> >where rules can be found in log in agreement and specifically listing it
> >in patch message when rule began to be enforced is not sufficient, what
> >method would be visible enough so rules could be enforced?
> 
> That's a reasonable question.
> 
> The problem with the current method - saying "look at this web page
> for the rest of the rules" is that it places the burden of reaching
> the content on the user - effectively it tells the user that she's
> responsible for knowing about and delivering any new rules to herself.
> 
> Further, it requires that users have a browser installed. Now, this
> may be splitting hairs, but the box that *I* have doesn't say anything
> about requiring a browser, just an Internet connection. So now, to
> abide by the rules of the game, I'm forced to keep a browser (and it's
> not a huge stretch to imagine a concerned parent removing the browser
> from Johnny's computer to keep him from seeing all that nasty porn).
> Effectively, Verant is dictating software requirements beyond what is
> actually needed for the game to function.
> 
> The reason posting it in a patch message isn't sufficient is that if a
> user doesn't play for some time, she may get multiple patches at once,
> and an older patch message may have been replaced by the original.
> 
> >I'm genuinely curious what method you think they should be using?
> 
> The first place, of course, would be printed documentation that comes
> with the physical media.
> 
> Obviously, with a huge and evolving game like Everquest rules are
> going to change to cover new problems and possibilities. When this
> happens, a text file version of the *complete* rules should be updated
> and sent to our computers as part of the conventional patching
> process, with notification that the rules have been updated, and an
> indication of the file name to read.
> 
> This is still imperfect, as a user may miss an individual patch
> message where the new rule is announced, but at least the rules will
> have been delivered *by Verant* for the users' reading pleasure. This
> last problem could be resolved by a more robust patching process, but
> that's a topic unto itself.
