>> 2) Why did the Everquest group move to rec.games.computer.everquest?
>> ---------------------------------------------------------------
>>
>> - Propagation. Since there are no formal rules for creating and
>>   removing groups in the alt.* hierarchy, some sites only carry a
>>   limited set of alt.* groups, or do not carry any of them because of
>>   the additional workload they put on the administrator. On the other
>>   hand, every site carries groups in the rec.* hierarchy. In 1999 the
>>   readers of a.g.everquest chose to move to the rec.* hierarchy in
>>   order to reach a wider audience and make sure that nobody is
>>   deprived from discussion about Everquest.
>>
>> - Room for expansion. One group (rec.games.computer.everquest) was
>>   created at first, in December of 1999. If traffic and content
>>   distribution dictates, we can create more groups underneath the
>>   rec.games.computer.everquest.* hierarchy. These groups will have
>>   a good propogation, which is simply not possible if they had been
>>   created as sub-groups of alt.games.everquest. This is a consequence
>>   of the expansion of Usenet in the last several years and the
>>   increased number of people abusing the freedom to easily create
>>   alt.* groups by creating "joke" groups, thus causing the vast
>>   majority of admins to ignore all future requests for groups.
>>
>> - Amount of traffic. Alt.games.everquest commonly holds over 800
>>   posts per day. Usenet lore states that any newsgroup receiving over
>>   200 posts per day deserves its own big8 group.
>>
>> 3) Who decided what, and when?
>> ------------------------------
>>
>> - The creation of a big8 newsgroup for Everquest was discussed in
>>   alt.games.everquest in early 1999. After a few weeks, a formal
>>   Request For Discussion (RFD) was posted to alt.games.everquest.
>>   This was closely followed by a Call For Votes (CFV), asking the
>>   readers of alt.games.everquest to vote for or against the move to
>>   the new groups. This first vote failed due to general lack of
>>   interest and bad timing... Everquest had just been released, the
>>   group was flooded with complaints about connectivity, and the
>>   CFV got lost in the rush. This process was repeated in September,
>>   the CFV following the RFC. The results were published on January
>>   28th 1999 and showed that a large majority of readers (163:31)
>>   decided that the new group was desirable. So here we are.
>>
>>   The full text of the RFC, CFV, and results of the Usenet vote will
>>   be available soon (the failed vote is there now) at the following
>>   URL:
>>   ftp://ftp.uu.net/usenet/news.announce.newgroups/rec/rec.games.compu
>> ter.everquest
>>
>> - The way Usenet works regarding the creation or removal of groups
>>   is often confusing.  Several articles try to describe it and you
>>   should read them if you want more information about this.  Take a
>>   look in news.announce.newusers and news.answers, and read the
>>   following articles: "What is Usenet?", "What is Usenet?  A second
>>   opinion.", "How to Create a New Usenet Newsgroup", "Guidelines on
>>   Usenet Newsgroup Names".  Read them in that order if possible.
>>   They will give you more information and explain things better than
>>   this FAQ.
>>
>> 4) Why do I still see alt.games.everquest at my site?
>> -------------------------------------------------
>>
>>   Some sites ignore all rmgroup control messages for alt.* groups and
>>   only remove a group if it had no traffic for three months or more.
>>   On these servers, the only way to make sure that
>>   alt.games.everquest is removed or aliased to
>>   rec.games.computer.everquest is to e-mail the
>>   news administrator (usually by sending a message to the address
>>   "news", "newsmaster" or "usenet" at your site) or wait until no
>>   more messages are posted in this group... which will probably never
>>   happen because of the amount of spam cross-posted all over Usenet.
>>
>>   However, don't do that *yet*! The first rmgroup control message for
>>   alt.games.everquest will not go out for two months, on February
>>   15th 2000. You don't want to get alt.games.everquest removed before
>>   everybody switches, do you?
>>
>> 5) Can I do something about this?  How can I help?
>> --------------------------------------------------
>>
>> - If your news server or ISP does not yet get r.g.c.everquest, tell
>>   them about it! Email newsmaster, news, and usenet@yourisp.com and
>>   ask them to add the new group.
>>
>> - Whenever you post a followup to an article which is cross-posted to
>>   alt.games.everquest, you should try to direct the followups out of
>>   that group so that the discussion continues only in the groups that
>>   are available to everyone.  There are two ways to do this: either
>>   remove alt.games.everquest from the list of groups when you post
>>   your followup, so that your articles and those that follow it will
>>   not be posted to the old group, or set the "Followup-To:" line in
>>   the header of your article, directing future followups out of the
>>   old group.
>>
>>   If your newsreader allows you to edit the "Followup-To:" line in
>>   the header of your article, this is a very convenient solution.
>>   Note that using the "Followup-To:" line only gives an indication to
>>   other people, but they can always change the list of groups if they
>>   want to. Moving groups is a cooperative effort and it will only
>>   work if the members of the Everquest community help and inform each
>>   other.
>>
>> - Inform people about the replacement of a.g.everquest by the new
>>   group.Tell the other readers that they should stop posting in the
>>   old group in order to reduce the duplication of resources and make
>>   it easier for newcomers to move to the r.g.c.everquest group.
>>
>>   You can explain this in the body of your article or combine this
>>   with a short note informing readers about where followups to your
>>   article should go.  Here's an example:
>>
>> [a.g.e removed from followups because it has been replaced by
>> r.g.c.everquest]
