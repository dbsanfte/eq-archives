You get an alt group by requesting it, possible address support@your-ISP

However finding a name on the list at isc.org does not equate to a
viable newsgroup. These groups are not carried by many servers. Some
ISPs will want to see traffic first and these groups have little to
none. Check Deja for articles not crossposted to the main group. 

As for alt.games.everquest.binaries that's an improperly named binary
group and most ISPs won't carry it. (  All binaries must be named
alt.binaries.* )
