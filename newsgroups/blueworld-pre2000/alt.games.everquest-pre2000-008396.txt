If you are running Win98 (not sure if it is in win95/win2k and is not in
NT),  Select 'start' then 'run' and then enter "msconfig" in the box.
This is a little application that will show you everything run in your
config.sys, autoexec.bat, system.ini, and start menu..

You can then selectively disable items that you do not want autostarted.
This will also show you many things that are not obviously started
because they don't create windows or task bar entries (such as find
fast).
