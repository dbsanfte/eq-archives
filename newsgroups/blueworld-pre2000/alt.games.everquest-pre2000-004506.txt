The need for new servers has absolutly nothing to do with the need to split
older overcrowded servers.  New servers are added for those that have just
bought the game and are starting their first character.  Splitting servers is to
help with the overcrowding on existing servers.  New servers have little or no
effect on alleviating the problem of overcrowding on old servers (imo), because
people are unwilling to leave their high level characters and restart on a new
server.

Starting a new character on a new split server will be no different for a newbie
then starting a new character on the original server before it was split.  Right
now there is a greater need for splitting servers then there is a need for
completely new servers (imho).  If however there are a sufficient number of
completely new accounts registered, then Verant should bring up another
completely new server in addition to splitting the overcrowded older servers.
