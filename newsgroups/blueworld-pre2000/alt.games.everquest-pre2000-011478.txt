Ok, honestly?  What I'd do is:

Make sure that all cards are installed on the motherboard that you intend to
use.  Leaving hardware off your motherboard is the main step in solving
hardware problems.  This is probably not a hardware problem.

Make sure that you have a bootable floppy that can access your CD-ROM drive
and that has at least FORMAT.COM on it (I recommend that this disk also have
FDISK on it, though you don't need it in this case).

Back up anything you want to keep  (for me, it'd be the folder
c:\windows\favorites)
Format C: again
Reinstall Win98SE
Install what ever internet connection software you have to.
Get DX7.0a and install it
Install the latest sound drivers that you find at the sound card's website
Install the video drivers that Verant suggests at their website (Video FAQ).
It won't be the latest, but they're "proven" (heh) to work with EQ.
