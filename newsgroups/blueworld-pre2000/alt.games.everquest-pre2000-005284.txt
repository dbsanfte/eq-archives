Graphics code is very easy to write (if you use OpenGL or something sane
like that).  UI code is tedious to write and very hard to write well
(because the person writing the interface knows what is supposed to 
happen and it is difficult to approach an interface as a novice user).
Database code is easier to get right, but consistency and deadlock issues 
make it a pain.  Network code is annoying all hell.

The issue here is interface, not graphics.  I agree that allowing people
to manipulate the contents of containers in the bank should not be a 
horrible problem.  However, there may be some hidden issue that we are
not aware of.  Maybe bags in the bank are stored as packed objects instead 
of containers to save storage ... or something like that.

There is an interface issue for opening bags on corpses.  Right click
already has a meaning: it puts the bag into your inventory.  Personally,
I like that interface because it makes the common case fast.  If we wanted
to be able to loot items out of bags on a corpse, we would have to give up
that shortcut.
