That's not an EQ tech issue, it's a Windows issue; if you have more than one 
hard drive (or more than one partition), you can tell Windows to use any 
read/write drive for the swap space (although a Zip, Jaz, or floppy would be, 
uhm, less than optimal...).

Go to Start | Settings | Control Panel | System

Select the Performance tab and double-click Virtual Memory.

NEVER let Windows manage your virtual memory - Windows is a moron.  Select 
your fastest drive (if you have more than one), and set the size of the swap 
file to 2x your actual RAM, both minimum and maximum.  If you ever get an "out 
of memeory" error, increase that to 3x.
