"Paul Gilbert" <paul@lancom.com.au> writes:

> Or they just rewrote it for the hell of it. It may come as
> a surprise to you, but software companies rewrite their
> software completely all the time for new versions, rather
> than just patching new features onto an existing
> version. I'd certainly doubt that Word 2000 has, for
> example, has any of the coding used in the original DOS
> version.

Actually, it wouldn't surprise me at all if it did.  In the
floppy drives I owned for my Commodore 128, there were large
chunks of code that didn't do anything, because the same
code had been re-used down through several generations of
drives.  For example, they were single-disk drives, but they
had code for choosing between multiple disks.  And these
were machines with 8K of RAM, so it's not like they had tons
of memory to waste! :-)

If you were writing a brand-new word processor, then no, you
wouldn't start with code from an old DOS version.  But it
doesn't work that way.  There are lots of versions along the
way, and each one is just a little different from the last,
so each one builds on the code of the previous one.  It
wouldn't be any surprise if some code from version 1 was
still around in version 2000.
